## 마법 수정

M4의 하강하는 전기/레이저 동작은 유지하며 시작을 완만하게 하고, 주파수 이동과 감쇠 시간을 늘렸다. 거친 FM 성분과 스침음의 비중을 줄이고 고역을 정리했다.
원본 약 0.226초 → 수정안 약 0.421초. 소리의 길이만 변경했으며 투사체 비행 속도나 턴 진행은 변경하지 않았다.

- 00_magic_before_after.wav: 원본 3회 → 수정 3회.
- 00_selected_six.wav: 마법 → 생물 명중 → 단단한 대상 명중 → 플레이어 피격 → 착지 → 불길. 각각 2회.
- references/M4-original.wav: 비교용 원본.
- selection-manifest.json: 선택과 측정 기록.

## 소리 밀도 방향

사용자는 효과음이 너무 많아지는 부담을 언급했다. 우선 선택한 여섯 종류로 시작한다.
적 여러 마리가 동시에 행동할 때 같은 소리의 재생 수를 제한하고, 플레이어 피격이 다른 소리에 가려지지 않게 한다. 쇠뇌를 추가한다면 실제 플레이에서 예고/발사 중 무엇이 필요한지 다시 판단한다.
`GameAudio`에 일반 효과 3음성 + 피격 전용 1음성, 동일 착지·불길의 중복 제한, 종류별 재생 간격과 음량을 적용했다.
ESC 메뉴에서 효과음·음악을 각각 0~100%로 조절한다. 드래그, −·+ 버튼 또는 포커스된 슬라이더의 좌우 방향키를 사용하며 설정은 다음 실행에도 유지한다.
초기 효과음 60%, 음악 50%. 소리 길이와 재생 제한은 턴 완료를 지연시키지 않는다.

## 검증

마법 수정안의 WAV 형식, 길이, 클리핑, 끝부분 감쇠를 확인했다.

신호 검사는 사용자 음색 평가나 실제 게임의 동시 재생 평가를 대신하지 않는다.
