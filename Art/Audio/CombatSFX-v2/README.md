# Grid-Caster 효과음 후보 64개 — v2

8종 × 각 8개 디자인 방향. 기존 v1은 보존했다. 이번 후보는 CC0 소재 편집과 직접 합성 레이어를 조합한 청취 시안이며 게임에는 연결하지 않았다.

## 듣는 방법

audition.html을 브라우저로 열면 인터넷 없이 64개를 개별 재생하고 종류별 비교·후보 선택·선택 결과 복사/저장을 할 수 있다. 페이지는 자동 재생하지 않는다.

auditions 폴더의 종류별 WAV는 후보 1→8을 각각 두 번 재생한다. 같은 후보의 재생 사이 간격은 0.35초, 다음 후보까지는 0.9초다. 개별 파일은 candidates 폴더에 있다.

이 8개씩은 최종 게임의 랜덤 재생용 미세 변형이 아니라, 디자인 방향을 선택하기 위한 후보다. 선택한 방향으로 2–3개의 작은 변형을 제작하는 것은 다음 단계다.

## 이번 제작 방식

- 마법: 천·책장·유리·종 소재와 FM, 공명, 입자 편집, 짧은 지연.
- 생물 명중: 천·가죽·부드러운 충격 소재를 중심으로, 소수의 마법 성분만 추가.
- 단단한 대상: 철판·금속 용기·돌 계열·유리의 실제 소재 소리 중심.
- 플레이어 피격: 몸 충격에 의복·작은 하강 피드백을 조합.
- 착지: 지면 충격 + 갑주 또는 가죽의 지연된 움직임. 일부 후보만 보조 저음.
- 불길: Fire Crackling 소스의 구간을 편집하고 천 스침·불씨 입자·바람을 조합.
- 쇠뇌 장전: 걸쇠·목재 삐걱임·가죽·기계 반복 동작.
- 쇠뇌 발사: 현의 Karplus–Strong 모델 + 목재/금속 해제음 + 공기 스침.

여러 소리를 무조건 더하는 대신 각 레이어에 공격 시작, 몸통, 동작, 잔향 등의 역할을 지정했다. 64개 모두 서로 다른 소재 조합이며 각 후보의 구체적 소스·레이어·수치는 asset-manifest.json에 기록했다.

## 검증과 한계

48kHz, 16bit PCM, Mono. 64개 WAV 형식, 64개 고유 해시, 클리핑 없음, DC 오프셋, 끝부분 감쇠를 확인했다.
청취 페이지에서 64개 브라우저 디코딩, 개별 재생, 정지, 선택 저장을 확인했다.
신호/페이지 검증은 음악과 적 여러 마리가 겹치는 실제 게임 청취 검증이나 사람의 음색 평가를 대체하지 않는다.
