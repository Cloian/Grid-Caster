# 전투 효과음 청취 시안 v1

2026-10-03 제작. 외부 샘플이나 음원 모델을 사용하지 않은 직접 합성 WAV 시안이다.
48kHz / 16bit PCM / Mono. 게임과 Unity 씬에는 아직 연결하지 않았다.

## 청취 순서

00_audition_all_8.wav는 아래 8종을 순서대로 각 3회 재생한다. 총 23.02초.
각 항목 안에서는 0.35초, 항목 사이에는 1초의 간격이 있다.

| 번호 | 파일 | 종류 |
| --- | --- | --- |
| 1 | 01_spell_cast.wav | 플레이어 마법 발사·짧은 비행 |
| 2 | 02_spell_hit_soft.wav | 부드러운 몸에 마법 명중 |
| 3 | 03_spell_hit_hard.wav | 갑주·단단한 대상에 마법 명중 |
| 4 | 04_player_hurt.wav | 플레이어 일반 피격 |
| 5 | 05_knight_land.wav | 기갑기마 착지 |
| 6 | 06_fire_trail_sweep.wav | 아르마딜로 불길 펼침 |
| 7 | 07_rook_charge.wav | 쇠뇌 장전 |
| 8 | 08_rook_fire.wav | 쇠뇌 발사 |

## 방향

마법은 맑은 합성음과 짧은 공기 마찰을 조합했다. 몸 명중은 둔한 충격, 단단한 대상 명중은 짧은 금속 공명을 넣었다. 플레이어 피격은 낮게 떨어지는 음으로 구분한다. 기갑기마 착지는 저음 충격과 갑주 흔들림, 불길은 퍼지는 잡음과 미세한 불꽃 성분, 쇠뇌는 걸쇠·줄 당김·짧은 기계 충격으로 구성했다.

미세한 음색을 판단하는 1차 시안이며, 실제 게임에서 여러 소리가 겹칠 때의 믹스와 반복 피로는 검증하지 않았다. 기존 상용 팩 소리는 사용하지 않았다.

## 검증

생성 시 8개 파일의 WAV 디코딩, 샘플레이트, 채널, 샘플 길이, 클리핑, DC 오프셋, 첫/끝 샘플과 마지막 20ms 감쇠를 확인했다.
측정값은 asset-manifest.json에 기록했다. 청취 취향·게임 적합성 검증과 별개다.
평균 RMS 목표는 -20dBFS이며, 날카로운 피크가 있는 클립은 피크 제한을 우선했다.
