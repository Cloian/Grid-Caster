# PC를 전체 보드 경험의 주력 플랫폼으로 삼는다

보드 전체의 관계를 읽고 의도한 빌드를 실행하는 경험을 우선해 PC를 주력으로 개발하며, 모바일은 보조 실험으로 보존한다. 모바일 웹의 접근 편의보다 작은 화면에서 보드의 존재감과 판독성이 약해졌다는 사용자 피드백을 우선했으며, 플랫폼과 배포 수단은 분리해 PC 웹 링크도 검토할 수 있다.

## Consequences

- 모바일 어댑터를 삭제하지 않지만 그 제약을 PC 핵심 설계의 기준으로 삼지 않는다.
- 결정 당시 모든 Web 실행에 모바일 UI가 적용됐다. 후속 PC 화면 작업에서 소스의 데스크톱/모바일 브라우저 분기를 분리했다. 공개 배포 여부와 사람의 판독성 검증은 [별도 기록](../verification/pc-screen-baseline-2026-10-02.md)으로 판단한다.
- 화면 복원만으로 재미가 개선됐다고 판단하지 않고 실제 보드 판단을 검증한다.
