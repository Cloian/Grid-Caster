# 제한적 강화와 보드 유물을 함께 사용한다

Grid-Caster의 런 내 성장은 2·6·10·14·18웨이브의 상한 있는 일반 강화 3택1과 4·8·12·16웨이브의 보드 위 유물 제단을 함께 사용한다. 유물 웨이브에서 실제로 유물을 획득하고 전투를 끝낸 경우에만 단계별 상급 강화 3택1을 추가로 제공한다. 각 유물 웨이브에서는 나이트·비숍·룩을 순서대로 해금하고, 16웨이브부터 모든 기믹을 혼합한다. 선택 횟수를 일반 강화 5회와 상급 강화 최대 4회로 제한해 한 런에서 모든 빌드를 완성하지 못하게 하며, 유물은 위험한 이동과 규칙 변화를 제공한다.
