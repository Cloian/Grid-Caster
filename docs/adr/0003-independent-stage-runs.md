# 스테이지마다 독립된 런과 새 빌드를 구성한다

각 스테이지를 고정 맵과 보스 포함 약 30분을 목표로 하는 독립 런으로 구성하고, 다음 스테이지에서는 런 내 성장을 초기화한다. 빌드 이월의 지속적인 강함보다 새 맵의 기믹을 배우며 다시 성장 선택을 하는 경험을 우선하며, 사망 시 현재 스테이지를 새 빌드로 재도전하되 이전 클리어 기록은 보존한다.

## Consequences

- 런 상태와 클리어 기록을 분리해야 하며 영구 능력치 성장은 도입하지 않는다.
- 완성 빌드의 보상은 해당 스테이지 보스에서 검증하도록 설계한다. 이 재미가 이미 검증된 것은 아니다.
- 공통·스테이지 전용 선택지와 시작 후보로 다양성을 만들되, 맵 전환·기록·고유 보스는 아직 후속 구현이다.
