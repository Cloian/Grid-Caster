## 적용 대상과 범위

기존 uGUI와 폰트·아이콘·보드 배치를 유지했다. 씬·프리팹·스프라이트·패키지·렌더링 설정은 이번 작업에서 수정하지 않았다. 상세 설명창은 확인할 때만 열리는 모달이며 영구 HUD 영역을 추가로 넓히지 않는다.

## 변경 내용

* 증강은 실제 구현을 기준으로 발동 조건·대상·수치·횟수 제한·불리한 효과를 풀어서 설명한다. 선택 카드의 현재 레벨과 선택 후 레벨을 분리했다. 이전 `2/2`는 선택 후 중첩 수였으나 현재 상태처럼 읽히는 문제가 있었다.
* 빈도 강화는 평균 발동 확률 변화로 설명한다. 예: 빠른 영창 `20% → 25% → 33.3%`. 기존 공격 묶음 안에서 한 번 발동하는 규칙은 유지하며, 독립 확률 추첨이 아니라는 점과 진행 중인 묶음 이후에 변경이 적용되는 점을 설명한다.
* 선택 카드의 상세 버튼, 보유 증강·유물 행, 시작 특성·이동술 HUD, 현재 제단을 클릭하면 전체 조건을 볼 수 있다. 유물 교체 화면에서도 효과·조건 상세 버튼을 제공한다. Esc·닫기·바깥 클릭으로 닫는다.
* 설명 확인은 턴을 소비하지 않는다. 확인 중 이동·공격·보상 선택을 차단하며 기존 공격 방향 선택을 보존한다. 창을 닫은 클릭이 같은 프레임에 뒤쪽 보드로 전달되지 않도록 보호했다. 기존 보상·추가 공격 대기 잠금을 임의로 해제하지 않는다.
* 이동술 선택은 습득·연마·교체를 구분한다. 실제 이동술 최대 레벨은 Lv.3이고 교체하면 레벨을 유지한다. 나이트 Lv.2는 착지와 상하좌우 불길 제거, Lv.3은 도약 후 다음 공격 첫 직격 피해 +1을 추가한다. 비숍은 대각선 최대 3→4→5칸, 룩은 직선 최대 4→5→6칸이다. 인접 한 칸 이동은 기본 이동으로 처리되는 조건도 상세 설명한다.
* 최대 중첩 증강·최대 이동술 연마·동일 이동술 재습득은 후보에서 제외하며 선택 API에서도 거절한다. 효과 없이 최대 레벨 연마 보상을 소비할 수 있던 경우를 방지한다.
* 위험 제단은 안전보다 상위 등급이 남아 있으면 반드시 상위 등급을 제공한다. 최소 희귀를 우선하며, 상위 후보가 소진되었거나 안전 제단이 전설이면 동급을 제공한다. 안전보다 낮은 등급은 나오지 않도록 안전 제단 추첨에서도 위험 제단 후보를 남긴다. 등급 우위가 모든 빌드에서 개별 유물 효용의 우위를 뜻하지는 않는다.

## Unity 설정과 직접 확인 방법

추가 GameObject 생성, Inspector 할당, 태그·레이어·Collider 설정은 필요 없다. 기존 `SampleScene`의 HUD가 런타임에 버튼과 상세창을 구성한다.

1. 최신 Grid-Caster 프로젝트의 `Assets/Scenes/SampleScene.unity`를 열고 Play한다.
2. 시작 특성과 증강을 선택한다. 카드의 `상세` 버튼은 효과를 확인할 뿐 보상을 소비하지 않아야 한다.
3. 왼쪽 보유 증강, 오른쪽 유물/제단, 아래 특성/이동술 카드를 클릭한다. 설명창을 연 동안 A·S·보드 클릭으로 행동할 수 없어야 한다.
4. Esc 또는 닫기로 돌아온 뒤 기존 선택 방향이 남고 턴은 늘지 않았는지 확인한다.
5. 이동술 연마 카드에서 현재 Lv.1과 선택 후 Lv.2 및 새 효과를 확인한다. 적용 후 HUD는 현재 Lv.2를 표시해야 한다. Lv.3에서는 추가 연마가 제시되지 않아야 한다.
6. 4·8·12·16웨이브에서 두 제단의 이름·등급을 비교한다. 위험은 안전보다 낮은 등급이 아니며, 상위 후보가 남으면 높은 등급이어야 한다.

자동 보상 UI 검증은 Play 종료 후 씬을 저장하고 `Tools > Playtest > Validate Reward Usability`에서 실행한다. 픽스처로 성장 상태를 바꾸므로 정상 플레이 중 실행하지 않는다. 클릭 판정 검사는 Game 뷰를 렌더링하는 일반 Editor에서 실행해야 한다. 그래픽 없는 배치 실행은 Canvas의 Graphic.depth가 -1이라 실제 Raycast 검증에 사용할 수 없다.
