# 범위 공격의 범위 성장 — 2026-10-05

시작 특성 표시 이름은 이후 사용자 요청에 따라 **범위 공격**으로 변경했다. 내부 ID `damage_boost`는 유지한다.

사용자가 비슷한 피해 수치 강화·유물 대신 범위 모양이 성장하기를 요청했고, **8 → 12 → 16칸의 단계별 확장**을 선택했다. 기본 주변 8칸을 유지하고 폭발 증폭의 두 중첩을 바깥 십자, 바깥 X자로 바꿨다.

| 검토 항목 | 결정 |
| --- | --- |
| Feature / 분류 | 같은 피해로 다른 타일 배치를 타격하는 범위 성장 / Core |
| Purpose | 성장 때마다 피해 숫자만 올라가는 중복을 줄이고 새로운 배치를 공격하게 한다. |
| Player Experience | Lv.1은 두 칸 떨어진 상하좌우 적, Lv.2는 대각선 모서리의 적까지 한 발에 포함한다. |

| Simpler Alternative | 기존 주변 8칸에 피해만 더할 수 있다. 사용자 선택에 따라 타일 모양을 확장하고 조준과 실제 판정을 공유한다. |

## 모양

`#`는 파편 피해 칸, `O`는 직접 적중 중심, `.`는 타격하지 않는 칸이다. 플레이어 칸은 어떤 모양에서도 제외한다.

```text
기본 8칸        Lv.1 12칸      Lv.2 16칸
.....           ..#..           #.#.#
.###.           .###.           .###.
.#O#.           ##O##           ##O##
.###.           .###.           .###.
.....           ..#..           #.#.#
```

기본은 체비쇼프 거리 1의 8칸이다. Lv.1은 `(±2,0)`, `(0,±2)`를 더하고 Lv.2는 `(±2,±2)`를 더한다. 거리 2의 `(±2,±1)`, `(±1,±2)` 8칸과 거리 3 이상은 타격하지 않는다. 중심은 직접 피해만 받는다. 보드 밖·빈 칸은 추가 피해 대상을 만들지 않고, 범위 안의 성벽 룩은 포함한다.

`DamageBoostArea`의 정수 모양을 실제 피해와 F 미리보기에서 함께 사용한다. 조준 테두리는 보드의 유효 칸과 해당 칸의 룩만 포함하므로 실제 표시 수는 벽·플레이어 위치에 따라 8/12/16보다 적을 수 있다. 파편 연출은 해당 범위에서 실제 피해를 받은 적에게만 나온다.

## 성장과 유물의 역할

| 항목 | 적용 |
| --- | --- |
| 폭발 증폭 Lv.1/2 | 범위 8→12→16칸. 피해를 올리지 않는다. |
| 과충전·특성 심화 | 기존 직접 대상 피해 증가를 유지한다. |
| 특성 완성 | 현재 모양 전체의 파편 피해 +1. |
| 폭발 핵 | 중심 대상을 직접 처치했을 때 해당 공격의 파편 피해 +1. 중심 생존·주변만 처치한 경우에는 적용하지 않는다. 범위를 더 늘리거나 추가 폭발하지 않는다. |
| 잔광 회수·과잉 저장기 | 기존 다음 첫 직접 적중 보너스 저장을 유지한다. |

파편 피해는 `1 + 특성 완성 + (중심 직접 처치 && 폭발 핵 ? 1 : 0)`이다. 성장이 없는 기본은 피해 1, 특성 완성 후 2, 중심 직접 처치와 폭발 핵 조건까지 만족하면 3이다. 폭발 핵은 별도의 범위 강화 없이 기본 8칸에서도 작동한다.

이전 풀 성장의 주변 피해 5·최대 8칸과 비교하면 이번 풀 성장은 피해 2·최대 16칸, 조건부로 피해 3·최대 16칸이다. 모든 칸에 적이 있다고 가정한 명목 피해 합계는 이전 40, 현재 32 또는 조건부 48이다. 이 계산은 과도한 무조건 범위·피해 동시 상승을 막기 위한 설계 비교이며 실제 DPS·승률·최종 밸런스 증거는 아니다. 성장 초기에는 체력이 높은 적을 빨리 처치하는 힘보다 넓은 배치에 피해를 나누는 힘을 얻는다.

직격 +1, 충전 요구량, 일반 A·다른 특성, 첫 적중에 한 번 적용, 추가 턴·추가 충전·추가 폭발 없음, 주변 처치의 직접 처치 보상 제외는 유지한다. 기습 문장·교대 기계 등 다른 범용 인접 효과의 범위는 기존 8칸을 유지한다. 렌더·카메라·패키지·음원·씬 YAML은 바꾸지 않았다.

## Unity 확인

수동 GameObject 생성·컴포넌트 추가·Inspector 할당·태그·레이어·Tilemap·Collider 설정은 없다. SampleScene에서 범위 공격을 선택하고 폭발 증폭을 고른 뒤 A로 충전하고 F로 조준한다. Lv.1에서 바깥 십자, Lv.2에서 모서리까지 테두리가 보이고 그 칸의 적만 파편 피해를 받아야 한다. 폭발 핵은 중심 적을 직접 처치하는 공격과 생존시키는 공격을 비교한다.

자동 검증은 Unity 6000.4.0f1의 격리 복사본에서 실제 SampleScene을 실행한다. `Tools > Playtest > Validate Damage Boost Splash`는 성장·범위 검사를 함께 수행한다. 공개 Web은 갱신하지 않았다. 사람 플레이에서는 확장 칸을 활용해 대상·이동 순서를 바꾸는지와, 초반 피해 증가를 범위로 바꾼 성장이 충분히 만족스러운지 확인해야 한다.
