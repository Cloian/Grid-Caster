# 데미지 강화의 적중 범위 공격 — 2026-10-05

이 문서는 최초 범위 공격 적용 당시의 기록이다. 이후 사용자 선택으로 폭발 증폭을 범위 성장 8→12→16칸으로, 폭발 핵을 중심 직접 처치 시 파편 피해 +1로 바꿨다. 현재 성장 규칙은 [범위 성장](damage-boost-range-growth-2026-10-05.md)과 `GrowthAndRelics.md`를 따른다.

사용자가 데미지 강화의 약한 체감을 보고하고 ‘남은 피해 전이’와 ‘적중 범위 공격’ 중 후자를 선택했다. 기본 특성 공격을 직격 피해 +1과 적중 주변 8칸 피해 1로 변경했다. 기존 기본 피해 1 기준으로 직격은 2, 주변은 1이다. 일반 A 공격은 기존 피해·충전 규칙을 유지한다.

| 검토 항목 | 결정 |
| --- | --- |
| Feature / 분류 | 첫 직격 위치를 중심으로 주변 8칸 피해 / Core |
| Purpose | 강화·처치·초과 피해가 모두 있어야 나타나던 부가 효과를 기본 공격 특성에서 체감하게 한다. |
| Player Experience | 적이 모인 위치와 직접 처리할 대상을 골라 한 발로 여러 적의 체력을 줄인다. |
| Core Fun Contribution | 관통의 직선 배치, 더블의 처리 순서, 넉백의 충돌과 구분되는 밀집 배치 선택을 만든다. |
| Risk | 적 밀집과 성장 조합에서 총 피해가 크게 증가한다. 현재 수치는 첫 플레이 비교값이며 승률·다른 빌드와의 최종 균형은 확정하지 않았다. |
| Simpler Alternative | 직격 피해만 올리거나 전이 조건만 완화할 수 있다. 이번에는 사용자 선택에 따라 범위 공격을 적용하고 전용 전이를 제거했다. |

## 판정과 표시

- F/특성 아이콘으로 확정한 데미지 강화 공격의 첫 직접 적중에서 한 번 폭발한다. 직격 대상을 처치하지 않아도 적용하고, 처치했어도 같은 적중 타일에서 적용한다. 빗나감·벽 적중은 폭발하지 않는다.
- 체비쇼프 거리 1인 주변 적 모두가 피해를 받는다. 대각선·성벽에 장착된 인접 룩도 포함한다. 직접 대상은 직격만 받고 플레이어는 주변 피해를 받지 않는다.
- 주변 처치는 추가 폭발·특성 충전·직접 처치 보상을 호출하지 않는다. 직접 처치용 회복·무료 이동·다음 공격 저장은 직접 대상의 처치만 인정한다. 기존 범용 유물의 독립 효과는 각 유물 규칙을 따른다.
- 공격 행동·적 턴·기본 충전 3회는 유지한다. F가 준비되어 있어도 일반 A는 폭발하지 않으며 준비 상태를 유지한다.
- 실제 조준 경로의 첫 대상 주위에 주황색 타일 테두리를 표시한다. 빈 이동 가능 칸과 인접 성벽 룩을 포함하고 플레이어 칸은 제외한다. 취소·확정·일반 공격·빗나감에서는 범위 표시를 지운다. 타일 테두리는 기존 Point 필터·32 PPU 절차 스프라이트를 재사용한다.
- 실제 HP가 줄어든 각 적에는 기존 섬광·반동·처치 잔상·효과음을 적용한다. 카메라 흔들림이나 전투 대기 시간을 추가하지 않는다. 별도 최종 아트·음원·패키지·씬 YAML 변경은 없다.

## 성장 정리

기존 ID는 유지하여 에셋 연결을 보존했다. 런 내 성장 저장은 현재 구현 범위가 아니므로 새 런부터 비교한다. 강화·유물의 개수와 획득 시점은 유지한다.

| 항목 | 새 효과 |
| --- | --- |
| 고밀도 마력 | 충전 요구 일반 적중 3→2→1회, 기존 유지 |
| 과충전 Lv.1/2 | 직격 피해 추가 +1/+2, 주변 피해는 유지 |
| 초과 전달 → **폭발 증폭** Lv.1/2 | 주변 피해 추가 +1/+2, 기본 주변 피해 1→2→3 |
| 특성 심화 | 직격 피해 +1 |
| 특성 완성 | 주변 피해 +1 |
| 분배 핵 → **폭발 핵** | 주변 피해 +1 |
| 잔광 회수·과잉 저장기 | 직접 대상 생존/직접 처치에 따른 다음 공격 저장, 기존 유지 |

주변 피해는 `1 + 폭발 증폭 중첩 + 특성 완성 + 폭발 핵`이다. 직격은 기본 2에 과충전·특성 심화 및 기존 공통 직격 보너스를 더한다. 피해 특성의 초과 전달 한도·두 대상 분배는 제거했다. 범용 전설 유물 **유리 심장**의 직접 처치 초과 전달(한 명·최대 2·행동당 한 번)은 독립 효과로 유지한다.

## 검증 범위

Unity 6000.4.0f1 격리 복사본에서 실제 SampleScene, 조준·입력 API, 직격·주변 피해, 점유 해제와 적 턴을 실행한다. 다른 프로젝트의 열린 Editor는 제어하지 않는다. 원본 결과는 `docs/verification/damage-boost-splash-*`에 보관한다.

검증은 기능·회귀 검사이며 정상 런 승률이나 사람의 재미 개선을 측정한 결과가 아니다. 공개 Web은 갱신하지 않았다. 사람 플레이에서는 범위 공격을 위해 대상·공격 시점이 달라졌는지, 초반 기본 효과가 충분한지, 폭발 증폭 성장 후 밀집 전투가 지나치게 쉬워지는지를 확인한다.
