# 타격 피드백 통합 — 2026-10-04

단일 요소 비교 뒤 사용자가 승인한 여덟 요소를 실제 Unity 전투에 모두 적용했다. 이전 잠정 순위는 단독 개선에 대한 설계 판단이며, 이번 조합의 체감 순위나 사람의 평가를 의미하지 않는다.

| 요소 | 적용 기본값과 동작 |
| --- | --- |
| 피격 반동 | 실제 HP 감소마다 공격 방향으로 원본 3픽셀 반응, 90ms 안에 복귀. 플레이어·적·처치·범위/환경 피해에 공통 적용 |
| 처치 잔상 | 사망 직전 스프라이트를 140ms 동안 반동·축소·소멸. 점유는 즉시 해제하며 잔상에는 전투 컴포넌트를 붙이지 않음 |
| 명중점 섬광 | 대상의 보이는 중심에 흰색 네 방향 도형, 80ms. 기존 붉은 피격 점멸도 유지 |
| 넉백 이동 | 기존 목적지까지 110ms 시각 이동. 타일 좌표와 점유 갱신, 벽/캐릭터 충돌 규칙은 그대로 유지 |
| 적 턴 전 간격 | 마지막 시전 완료 후 적중한 공격에 80ms. 넉백이 남으면 이동 표현까지 기다린 뒤 적 턴 시작. 추가 시전 사이에 반복 간격을 넣지 않음 |
| 발사음 감쇠 | 명중음 요청 때 재생 중인 발사음 꼬리를 원래 음량의 25%로 낮춤. 다음 발사는 원래 음량. 세 일반 음성이 발사음으로 찼을 때 명중음은 오래된 발사음을 대체 |
| 비행 시간 상한 | 시전별 60~250ms. 가까운 공격의 기본 속도는 유지하고 긴 경로만 가속. 관통 구간 모두 같은 마감 시간을 공유하며 추가 시전은 각각 독립 비행 |
| 카메라 흔들림 | 실제 HP 감소마다 최대 2화면픽셀·70ms. 동시 명중 강도를 합산하지 않음. 화면 픽셀 단위 이동 후 원래 전체 보드 중심으로 복귀 |

`CombatFeedback`은 첫 피해 때 자동 생성한다. 씬에 수동으로 추가할 필요가 없다. 피격·넉백 중 원본 SpriteRenderer의 스프라이트, 애니메이션 결과, 색, 방향, 정렬을 별도 시각 SpriteRenderer에 복사한다. 원본 Transform, HP, 타일 좌표는 계속 규칙의 기준이다. 새 패키지·최종 아트·음원 교체는 없다. 절차적으로 만든 섬광 텍스처는 Point 필터와 32 PPU를 사용한다.

피해 방향이 없는 환경/범위 피해는 위쪽 반동을 기본값으로 사용한다. 카메라는 게임 RNG를 사용하지 않는다. 일시정지에서는 비행, 반동, 넉백, 잔상, 확인 간격이 모두 정지한다. 사망과 씬 재시작은 대기 중인 공격 전환을 취소한다. 효과음 길이를 턴의 완료 조건으로 삼지 않는다.

조절 위치: `CombatFeedback.cs`의 네 시간 상수와 반동 픽셀 값, `Move`의 공격 결과 확인 시간, `ProjectileManager`의 최소/최대 비행 시간, `CameraController`의 흔들림 픽셀/시간, `GameAudio`의 명중 시 발사음 감쇠 값.

## 검증

Unity 6000.4.0f1에서 원본 작업물을 보존한 격리 복사본의 실제 씬으로 실행했다. URP 사용을 먼저 확인했다.

- [피드백 검사 43조건](../verification/combat-feedback-2026-10-04.txt): 무피해 무연출, 반동 중 원본 좌표 유지, 처치 직후 점유 해제, 비전투 잔상 수명, 넉백 충돌과 도착, 일시정지, 준비한 관통·더블 캐스트·넉백 후 정확히 한 적 턴, 실제 발사 음성 감쇠와 다음 발사 원복.
- 먼 대각선과 두 대상 관통의 전체 비행은 각각 250ms, 일반 적중 후 적 턴 시작 간격은 약 83ms였다. 고정 120Hz 시간 단계의 제어된 픽스처 결과이며 실제 기기의 프레임 경계에서는 오차가 생긴다.
- [전투·UI 회귀 662조건](../verification/impact-feedback-chess-2026-10-04.txt), [오디오·일시정지·재시작 회귀 38조건](../verification/impact-feedback-audio-2026-10-04.txt) 통과.
- 실제 URP 카메라로 [생존 피격](../verification/captures/impact-feedback-recoil.png), [처치](../verification/captures/impact-feedback-lethal.png)를 렌더하고 확인했다. 두 캡처는 전투를 구성한 픽스처이며 보드만 포함한다.

사람의 청취 선호, 장시간 카메라 피로도, 타격감의 최종 우열은 아직 측정하지 않았다. 이번 작업은 로컬 Unity 소스에 적용했으며 기존 공개 Web 링크는 갱신하지 않았다.
