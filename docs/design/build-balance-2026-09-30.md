# 빌드·강화·유물 밸런스 검토

작성일: 2026-09-30. 상태: **코드 적용 / 독립 시드 자동 런 96회 + 전설 회피 32회 검증 / 인간 승률 미측정**.

기준은 `SampleScene`, `RunProgressionCatalog`, `RunProgressionSystem`, `PlayerTraitSystem`, `Move`, `MonsterSpawner`, `StageFlowManager`다. 2~3절은 최초 코드 대조 당시의 진단 기록이며, 4~8절은 적용된 판정·빌드 기준이다. 최신 실제 수치는 `GrowthAndRelics.md`와 `ChessWaves.md`를 따른다. 보상 주기·적 체력 3·기본 공격 1은 유지하고, 고정 적 조합·나이트 도약 간격·회복량·일부 강화 효율을 자동 런 결과로 변경했다.

자동 조정의 추가 변경: 기본 클리어 회복 10%→30%, 나이트 1→2턴 간격, 최종전 25→18명. 메아리 탄두는 추가 시전 피해 +1과 관통, 긴 충격은 발동 피해 +1과 거리, 반향 압박·충격 봉쇄는 2→3명으로 정리했다. 이는 최초 제안 이후 실제 런에서 드러난 두 빌드의 처리력 부족을 보완한 값이다.

독립 시드 자동 클리어율은 더블 20.8%, 관통 37.5%, 데미지 54.2%, 넉백 8.3%였다. 네 빌드 모두 전설 없는 실제 완주가 확인됐다. [표본·수치·검증 한계와 원본 결과](../verification/balance-2026-09-30.md)를 함께 읽는다.

## 1. 결론과 설계 기준

문제는 유물 하나의 체력 비용만이 아니다. 선택 예산에 맞지 않는 완성 조건, 효과가 없는 상급 강화, 과도하게 중복되는 범위 피해, 처치하면서 사라지는 넉백 보상이 함께 있다.

* 일반 강화는 빌드의 기본 작동을 만든다. 전설 유물 없이도 20웨이브를 공략할 수 있어야 한다.
* 상급 강화는 공격·이동·생존 중 큰 방향을 고른다. 이름이 ‘완성’이라는 이유로 모든 전용 강화를 최대 중첩해야 하는 것은 아니다.
* 일반 유물은 작은 조건부 이득, 희귀 유물은 반복 가능한 전술·유지력, 전설 유물은 공격 형상이나 행동 순서를 바꾼다.
* 희귀도는 효과의 강함과 별개인 획득 조건이다. 전설을 필수 부품으로 설정하지 않는다.
* 최종 빌드는 공격력 하나가 아니라 **직격 피해 / 행동당 타격 수 / 범위 피해 / 봉쇄 / 이동 / 유지력**을 함께 산출한다.
* 수치만 높여도 해결되지 않는 다수 적 압박은 범위 처리와 봉쇄로 해결한다. 새 직업·게이지·필살기·영구 성장은 추가하지 않는다.

## 2. 실제 획득 난도와 선택 예산

### 현재 획득 경로

| 분류 | 획득 경로 | 실제 희소성 |
|---|---|---|
| 시작 전용 강화 | 시작 특성 전용 3종 중 1개 선택 | 세 항목이 전부 제시됨. 가장 확실한 기본 부품 |
| 나이트 도약 | 이동술이 없으면 2웨이브 보상에 반드시 제시 | 등장 보장이지 자동 획득은 아님 |
| 일반 전용 강화 | 일반 보상마다 미완성 전용 강화 최소 1개 제시 | 특정 항목은 보장되지 않음. 별도 희귀도·가중치 없음 |
| 일반 범용 강화 | 남은 후보에서 균등 추첨 | 전용 보장 자리가 없어 상대적으로 놓치기 쉬움. 구속 착지는 이동술 보유 후에만 등장 |
| 상급 강화 | 유물을 얻고 4·8·12·16웨이브를 클리어 | 그 단계의 3개 모두 제시. 확률보다 생존·접근 조건이 어려움 |
| 전설 유물 | 두 제단의 등급 추첨 후 해당 등급에서 추첨 | 특정 전용 전설이 가장 희소한 최종 부품. 필수 강화와 구분해야 함 |

따라서 현재 ‘가장 희귀한 일반 강화’라는 항목은 없다. **가장 늦고 까다로운 강화는 16웨이브 상급 강화**, **가장 희소한 빌드 부품은 특정 전설 유물**이다. 빠른 영창·얇은 장전·고밀도 마력·압축 충격은 기본적인 발동 주기 강화이며, 전설급 부품이 아니다.

| 웨이브 | 안전 제단 일반 / 희귀 / 전설 | 위험 제단 일반 / 희귀 / 전설 |
|---:|---|---|
| 4 | 70% / 28% / 2% | 50% / 40% / 10% |
| 8 | 57% / 35% / 8% | 37% / 47% / 16% |
| 12 | 40% / 45% / 15% | 20% / 57% / 23% |
| 16 | 0% / 70% / 30% | 0% / 55% / 45% |

위 표는 **등급 후보가 남아 있을 때의 의도된 등급 추첨**이다. 처음 4웨이브 안전 제단에는 전설 후보가 범용 3개 + 해당 특성 1개이므로 특정 전설의 제시 확률은 2% ÷ 4 = 0.5%다. 이후에는 이미 공개된 항목이 제외되어 확률이 달라진다. 실제 획득률에는 제단 도달·선택 여부도 들어가므로 이 수치를 획득률로 부르면 안 된다.

현재 후보 등급이 소진되면 `AddAltarOffer`가 전체 남은 후보를 정렬한 뒤 전체에서 균등 추첨한다. 정렬만으로는 가까운 등급 제한이 되지 않는다. 따라서 16웨이브에도 일반 유물이 나올 수 있다. **제안: 최소 품질을 만족하는 남은 등급 중 가장 가까운 등급의 후보만 추첨**한다. 완전히 소진됐으면 보상을 조용히 하향하지 말고 명시적인 대체 보상을 제공한다.

### 일반 강화 6회가 기준이다

20웨이브 입장 전 선택 수는 시작 1회 + 2~18 짝수 웨이브 9회 = 총 10회다. 유물을 네 번 모두 얻으면 일반 강화 6회, 상급 강화 4회, 유물 최대 4개다. 제단을 한 번 포기하면 상급 1회가 일반 1회로 바뀐다. 유물 공개는 최대 8개지만 획득은 최대 4개다.

| 시작 특성 | 현재 전용 강화 최대 중첩에 필요한 선택 | 나이트 도약까지 | 일반 6회 안에 모두 최대 강화 가능한가 |
|---|---:|---:|---|
| 더블 캐스트 | 6 | 7 | 불가능 |
| 관통 | 5 | 6 | 가능하지만 범용 공격·생존 강화 자리가 없음 |
| 데미지 강화 | 6 | 7 | 불가능 |
| 넉백 | 5 | 6 | 가능하지만 범용 공격·생존 강화 자리가 없음 |

이는 유물을 모두 얻는 경로의 예산이며, 유물을 포기한 일반 강화 경로에는 그대로 적용되지 않는다. ‘모든 최대 중첩 + 전설 네 개’는 기준 빌드가 될 수 없다.

**제안하는 핵심 완성:** 전용 3종을 1중첩씩 + 이동술 1개 + 필요한 범용 1개 = 일반 강화 5회. 남은 일반 1회와 상급 4회는 빈도·범위·이동·회복의 취향 차이를 만든다. 전설은 완성 빌드의 필수 조건이 아니라 최종 변형이다. 무작위 추첨 때문에 아래 예시 경로가 항상 제시되는 것은 아니다.

보상 횟수를 늘리기 전에 6회 안에 생존 가능한 작동형이 나오는지 검증한다. 10·14웨이브까지 기본 부품이 제시되지 않는 런이 빈번하다면, 먼저 해당 보상의 전용 보장 자리를 ‘아직 얻지 않은 전용 항목 우선’으로 바꾸는 간단한 보정부터 시험한다. 새 재추첨 화폐나 성장 화면은 만들지 않는다.

## 3. 현재 코드에서 확인한 문제

| 문제 | 플레이 영향 | 적용 우선순위 |
|---|---|---|
| 예리한 마력 +1피해/-1체력, 유리 심장 +1피해/-3체력 | 유물은 슬롯까지 사용하면서 같은 이득에 비용이 큼 | P0: 역할 분리 |
| 셔플 백 최소 2; 특성 완성은 백 -1 | 얇은 장전 최대 / 고밀도 최대 / 압축 충격 최대에서는 상급 강화가 무효 | P0: 특성별 완성 효과로 변경 |
| 모든 일반 강화 획득마다 셔플 백 재생성 | 생명·회복 강화조차 남아 있던 발동 진행을 초기화함 | P0: 크기가 안 바뀌면 백 보존, 크기 변경은 다음 백부터 |
| 새 이동술을 얻으면 레벨 1로 초기화 | 앞선 이동 연마 투자가 손실됨. 상위 이동술이라는 오해도 생김 | P0: 교체 시 숙련 레벨 보존 |
| 이동술 연마는 3레벨에서 증가하지 않음 | 효과 없는 선택 카드가 계속 등장 | P0: 무효 후보 제외·적용 가능한 범용 후보로 교체 |
| 넉백은 직격 후 살아 있는 적에게만 발생 | 원샷 세팅이 되면 특성·전용 강화·전용 유물의 상당 부분이 사라짐 | P0: 처치 시에도 주변 봉쇄가 남도록 보완 |
| 처치 효과 통지가 넉백 추가 피해보다 먼저 실행 | 철벽 못·도미노로 처치한 적은 성장 시스템의 처치 폭발·회복·왕의 차례에 잡히지 않음 | P0: 충돌까지 끝난 처치 결과로 통지 |
| 관통 파동이 추가 대상마다 중복 적중 | 밀집 적은 같은 파동 효과를 여러 번 맞음. ‘피해 2’가 사실상 훨씬 커짐 | P0: 같은 범위 효과의 행동당 중복 제한 |
| 봉쇄 후보가 생성 순서 기준, 이미 봉쇄된 적도 선택 | 겹친 효과가 낭비되며 당장 위협적인 적을 놓침 | P1: 미봉쇄·위협 우선, 예고에 대상 표시 |
| 기본 피해 1, 현재 모든 체스 적 체력 3 | 1→2는 3타→2타, 2→3은 2타→1타. +1의 가치가 선형이 아님 | P1: 처치 문턱으로 평가 |
| 과충전 2중첩은 발동 피해 4 | 체력 3 상대에서 첫 중첩의 피해 3과 같은 처치 횟수 | P1: 두 번째 중첩은 범위 효과로 변경 |
| 회복 호흡은 +5%p, 최종 회복은 올림 | 최대 체력 10에서는 1→2→2로 두 번째 중첩의 증가가 없음 | P1: 추가 회복을 정수로 명시 |
| 저장 보너스가 하나의 bool | 나이트 3레벨·기습 문장·과잉 저장기를 함께 얻어도 보너스가 제대로 합산되지 않음 | P1: 보너스 출처별로 기록 |
| 웨이브 시작 시 이동·저장 공격 보너스가 남음 | 다음 웨이브 첫 공격에 설명되지 않은 이득 발생 | P1: 공격 예약은 웨이브 종료 시 해제 |

유리 심장에 선택 이유가 전혀 없는 것은 아니다. 예리한 마력과 함께 얻으면 기본 피해 3으로 현재 체력 3 적을 모든 공격으로 원샷낼 수 있고, 4웨이브에서 다른 상급 강화를 고른 런에도 +1을 얻는다. 그러나 이것은 **조합의 문턱 효과**이지 유리 심장의 비용·등급 설계가 잘 맞는다는 근거는 아니다. 상급 강화와 유물을 동시에 가질 수 있으므로 두 보상을 서로 배타적인 선택으로 계산하지 않는다.

## 4. 적용된 공통 판정 규칙

새로운 상태 효과 종류는 만들지 않고 기존 피해·봉쇄·이동에 조건을 정리한다.

1. **직격:** 기본공격 각 투사체의 적중. 추가 시전·관통 적중도 직격이다. 행동 하나 안의 시전 순서와 관통 대상 순서를 사용한다.
2. **직접 처치:** 직격 또는 해당 공격의 넉백 충돌 피해로 사망. 같은 적의 처치 보상은 한 번만 발생한다. 폭발·파동·초과 피해로 죽은 적은 직접 처치 보상을 재발동하지 않는다.
3. **주변 8칸:** 적중 타일과 체비쇼프 거리 1인 타일. 중심 타일은 포함하지 않는다. 범위 안의 살아 있는 적을 판정하며, 이동 가능한 바닥 칸만으로 제한하지 않는다. 성벽에 있는 룩도 범위 피해 대상이다. 빈 벽·맵 밖에는 대상이 없고, 범위 피해와 지상 이동 넉백 면역을 혼동하지 않는다.
4. **범위 중복:** 같은 효과는 같은 플레이어 행동 안에서 같은 적에게 최대 한 번. 다른 효과의 피해는 합산한다. 관통 파동 2를 세 발동점에 걸쳐도 피해 6이 되지 않는다. 연쇄 폭발로 사망한 적은 새 폭발을 만들지 않는다.
5. **봉쇄:** 바로 다음 적 행동 한 번을 생략한다. 중첩은 지속 시간이 아니라 대상 수를 늘린다. 이미 봉쇄된 적을 제외하고 현재 근접 추격 적의 인접 공격·장전 룩 사선 위협, 플레이어 거리, 생성 순서 순으로 선택한다. 나이트의 실제 다음 착지를 선계산하는 우선순위는 없다. 룩은 이동 넉백에는 면역이나 행동 봉쇄에는 면역이 아니다.
6. **저장 피해:** 같은 출처는 중복 저장하지 않고 갱신한다. 다른 출처는 합산하고 다음 기본공격의 **첫 직격 한 번**에만 적용한다. 빗나간 공격도 예약을 소모한다. 재귀 시전·재귀 충전은 없다. 웨이브가 끝나면 해제한다.
7. **직전 이동 조건:** 일반 이동과 이동술 모두 인정하되 왕의 차례의 무료 이동은 인정하지 않는다. 대기·공격을 하면 직전 이동 조건이 끊긴다.
8. **방어:** 위험 무효를 먼저 적용한다. 남은 양수 피해에 착지 결계, 선봉의 방패 순으로 적용한다. 피해가 이미 0이면 다음 보호를 소모하지 않는다. 결계는 중첩 저장되지 않는다.
9. **진행:** 모든 추가 시전·범위·충돌·처치 효과·무료 이동이 끝난 뒤 적 턴 한 번. 몬스터 사망 점유는 즉시 해제한다. 미리 지정된 표적이 죽었으면 피해·처치 보상을 재통지하지 않는다.

## 5. 적용된 일반 강화와 상급 강화

### 일반 강화: 기본적인 빌드 부품

발동 주기·공격 형상·행동 봉쇄의 세 축을 유지한다. 이름이나 아이콘만 보고 희귀 강화처럼 오해하지 않도록 전용/범용, 중첩, 실제 선택 후 수치를 표시한다.

| 빌드 | 빈도 부품 | 형상·피해 부품 | 안전 부품 |
|---|---|---|---|
| 더블 캐스트 | 빠른 영창 2중첩: 백 5→4→3 | 메아리 탄두: 추가 시전 직격 피해 +1(고정), 추가 1→2명 관통 | 반향 압박: 추가 시전 첫 직격에서 주변 2→3명 봉쇄. 행동당 한 번 |
| 관통 | 얇은 장전 1중첩: 백 3→2 | 긴 바늘 2중첩: 발동 시 총 3→4명 직격 | 관통 파동 2중첩: 추가 대상의 주변 피해 1→2. 동일 적은 행동당 한 번 |
| 데미지 강화 | 고밀도 마력 2중첩: 백 4→3→2 | 과충전 1중첩: 발동 직격 피해 2→3. **2중첩은 첫 적중 주변 피해 1 추가**, 직격은 3 유지 | 잔광 구속 2중첩: 발동 첫 적중 주변 1→2명 봉쇄 |
| 넉백 | 압축 충격 2중첩: 백 4→3→2 | 긴 충격: 발동 직격 피해 +1, 밀기 1→2칸 | 충격 봉쇄: 생존 대상 우선으로 중심·충돌·주변에서 최대 2→3명. 처치·이동 불가도 발동하며 이미 봉쇄된 적은 제외 |

범용: 생명 연마는 +1 최대/현재 체력, 상한 3 유지. 연쇄 폭발은 피해 1→2·재연쇄 없음. 구속 착지는 착지 주변 봉쇄 1→2명. 회복 호흡은 클리어 기본 회복 `ceil(최대 체력 × 30%)`에 **+1→+2 체력**, 상한 2. 나이트 도약은 기존처럼 2웨이브에 반드시 제시한다.

### 상급 강화: 역할을 겹치지 않게 조정

특성 완성은 더블 캐스트의 모든 추가 시전 직격 피해 +1 / 관통의 모든 추가 관통 대상 직격 피해 +1 / 데미지 강화의 발동 첫 직격 주변 피해 +1 / 넉백의 발동 첫 적중 지점에서 살아 있는 중심·주변 적 최대 2명 봉쇄다. 넉백은 중심 생존자를 우선하고 이미 봉쇄된 적을 제외한다. 각 효과는 전설 없이도 작동하고, 빈도 최대 강화에도 무효가 되지 않는다.

3레벨 이동술에는 연마를 제시하지 않는다. 현재 보유 중인 비숍·룩을 다시 배우는 카드도 제외한다. 빠진 자리는 최대 중첩이 아닌 적용 가능한 범용 강화로 채우고 **실제 대체 항목의 이름·효과**를 표시한다. 숨겨진 보급 숫자로 바꾸지 않는다.

예리한 마력의 상시 피해를 발동 첫 직격으로 제한하는 이유는 ‘모든 공격 원샷’이 네 시작 특성의 차이를 지우는 것을 막기 위해서다. 여전히 유리 심장과 함께 선택할 수 있지만 효과 조건·체력 비용이 다르다.

## 6. 적용된 유물 21종

표의 횟수 제한은 특성 셔플 백과 별개다. 표에 없는 피해 추가·회복·연쇄는 발생하지 않는다. ‘다음 공격’은 빗나가도 소모하며, 모든 회복은 최대 체력을 넘지 않는다.

이 값은 ‘항상 집어야 하는 전설’을 목표로 하지 않는다. 체력 2의 손실이 실제 패배 원인이 될 수 있으며, 안전하게 원샷 문턱을 만들지 못하는 런에는 다른 유물이 더 좋을 수 있다.

## 7. 최종 빌드 산출 방식

### 계산 순서

`직격 피해 = 기본 1 + 피해 특성 발동 보너스 + 상시 직격 보너스 + 해당 직격의 조건부 보너스`.

피해 특성의 발동 보너스는 기본 +1, 과충전 1중첩이 있으면 +2다. 과충전 2중첩은 직격을 더 올리지 않고 범위를 추가한다. 예리한 마력은 발동 공격의 첫 직격에 +1, 사냥꾼의 인장·저장 보너스는 조건 충족 첫 직격에만 추가한다. 가시 바늘은 두 번째 관통 대상에만 +1, 쌍둥이 초점·메아리 탄두·더블 특성 완성은 추가 시전에만 적용한다. 긴 충격은 넉백 발동 직격에 +1이다.

셔플 백 평균 발동률은 `1 / 백 크기`지만 매 공격의 독립 확률은 아니다. 추가 시전은 백을 소비하지 않는다. 최대 일반 빈도는 더블 1/3, 관통 1/2, 데미지 1/2, 넉백 1/2이며 제안된 특성 완성은 이 빈도를 바꾸지 않는다.

실제 효율은 총 피해의 합이 아니라 다음을 기록한다.

* 행동당 직접 처치 수·범위 처치 수.
* 이번 공격 뒤 살아 있고 행동 가능한 적 수와 공격 가능한 적 수.
* 다음 적 턴에 봉쇄되는 서로 다른 적 수.
* 이동에 소비한 행동 수와 확보한 안전 착지 칸 수.
* 적 직선 정렬 여부, 밀기 후 빈 칸, 불길·적 투사체의 다음 위치.

아래 네 예시는 **각각 일반 6개 + 상급 4개만 쓰는 실제 가능한 선택 예산**이다. 제시 보장이나 클리어 보장이 아니다. 전설을 넣지 않은 네 최종형의 선택 예산과 핵심 피해·봉쇄 산출을 자동 단위 검증했다. 실제 런은 이 구성을 강제하지 않고 무작위로 제시된 보상 중에서 선택한다.

### A. 더블 캐스트: 관통하는 추가 탄 / 다방향 사격

* 일반 순서(시작 / 2 / 6 / 10 / 14 / 18): 빠른 영창 → 나이트 → 메아리 탄두 → 반향 압박 → 빠른 영창 → 연쇄 폭발.
* 상급(4 / 8 / 12 / 16): 이동 연마 → 이동 연마 → 교대 과충전 → 특성 완성.
* 최종 핵심: 백 3, 발동 시 2시전, 추가 시전은 총 2명 관통·직격 피해 3, 반향 압박 2명. 직접 처치 주변 피해 1. 이동 뒤 첫 직격 주변 피해 1. 이동은 나이트 3레벨.
* 전설 변형: 삼중 메아리면 3시전. 회전 거울이 함께 있으면 각각 다른 방향으로 쏜다. 전설 없이도 추가 탄의 관통과 봉쇄가 기본 형상이다.
* 실패 조건: 발동 전 단일 공격, 정렬되지 않은 적, 추가 탄이 닿을 대상이 없는 상황. 첫 대상이 살아 있으면 추가 탄이 먼저 같은 적을 맞힌다. ‘세 발 = 무조건 세 처치’가 아니다.
* 겹침 검사: 한 행동의 반향 압박 한 번, 각 시전의 메아리 관통 적용, 백 소비 한 번, 적 턴 한 번.

### B. 관통: 대열 절단 / 파동 전선

* 일반: 얇은 장전 → 나이트 → 긴 바늘 → 관통 파동 → 관통 파동 → 연쇄 폭발.
* 상급: 폭발 순환 → 비숍 교체 → 이동 연마 → 특성 완성.
* 최종 핵심: 백 2, 발동 총 3명 직격. 첫 대상 피해 1·추가 대상 피해 2. 파동 피해 2는 동일 적에게 한 번. 직접 처치 폭발 피해 2. 착지 봉쇄 1명. 비숍 2레벨 대각선 최대 4칸.
* 전설 변형: 무한 궤도는 직격 수 제한만 없앤다. 파동 중복 제한은 없애지 않는다.
* 실패 조건: 적이 줄을 이루지 않은 분산 배치. 첫 대상의 피해는 강화되지 않으므로 선두 체력이 높으면 처치가 늦다. 이동으로 대열을 만들어야 한다.
* 겹침 검사: 파동으로 먼저 죽은 예정 관통 대상은 직격/회복 횟수로 세지 않는다. 한 적이 서로 다른 파동 중심에 들어 있어도 파동 피해는 한 번.

### C. 데미지 강화: 확정 처치 문턱 / 처치 폭발

* 일반: 과충전 → 나이트 → 고밀도 마력 → 잔광 구속 → 연쇄 폭발 → 고밀도 마력.
* 상급: 폭발 순환 → 비숍 교체 → 이동 연마 → 특성 완성.
* 최종 핵심: 백 2. 발동 직격 피해 3으로 현재 체력 3 적을 원샷. 직접 처치 폭발 2 + 특성 완성 범위 1로 인접 적 피해 3. 살아남은 주변 1명 봉쇄, 착지 봉쇄 1명. 비숍 2레벨.
* 전설 변형: 폭렬 핵은 범위를 추가해 부상·다른 체력 문턱을 처리한다. 과잉 저장기는 발동 다음의 비발동 공격 첫 피해를 2로 만든다. 유리 심장은 기본/발동 피해를 2/4로 바꾸고 초과 직격 피해를 넘긴다.
* 실패 조건: 발동하지 않는 공격, 흩어진 적, 주변에 적이 없는 단독 목표. 광역 처치가 많아도 재폭발하지 않는다. 이동·방어를 버리고 공격만 반복하면 투사체와 접근 적에 포위될 수 있다.
* 겹침 검사: 폭발+특성 완성의 서로 다른 피해는 합산하지만 각각은 행동당 동일 적 한 번. 첫 직격의 범위만 발동.

### D. 넉백: 통로 확보 / 충돌 봉쇄

* 일반: 압축 충격 → 나이트 → 긴 충격 → 충격 봉쇄 → 충격 봉쇄 → 연쇄 폭발.
* 상급: 폭발 순환 → 이동 연마 → 교대 과충전 → 특성 완성.
* 최종 핵심: 백 3, 발동 직격 피해 2·밀기 2칸. 충격 봉쇄 최대 3명과 특성 완성 최대 2명은 같은 적을 중복 선택하지 않는다. 충분한 주변 적이 있으면 최대 5명 봉쇄한다. 착지 봉쇄 1명, 직접 처치 폭발 2. 나이트 2레벨.
* 유물 변형: 도미노로 충돌 피해, 철벽 못으로 이동 불가 피해, 파성추로 3칸과 대상·충돌 봉쇄. 나이트로 적 뒤로 돌아가 벽·다른 적 쪽으로 밀어낸다.
* 실패 조건: 밀어낸 뒤 다음 턴에 스스로 다시 인접하는 이동, 충돌시킬 적이나 벽이 없는 배치, 룩의 이동 면역. 룩도 봉쇄는 가능하다. 원샷한 경우에도 주변 봉쇄가 남으므로 성장하면 빌드가 사라지지 않는다.
* 겹침 검사: 0칸 이동 충돌, 이동 중 충돌, 룩 면역, 직격 원샷, 충돌로 두 적 사망을 각각 검사한다. 충돌 처치도 폭발·회복·왕의 차례에 한 번만 통지한다.

유물은 예시의 핵심 산출에 포함하지 않았다. 따라서 ‘전설 네 개를 전부 얻는다’ 같은 불가능한 조건으로 성능을 주장하지 않는다. 4개 슬롯에는 범용 방어·회복과 전용 형상 유물을 섞고, 특정 희귀/전설 조합은 별도의 최종 변형으로 평가한다.

## 8. 적용된 이동 방식

기본 이동은 8방향 한 칸. S키가 기본 이동과 현재 이동술의 빈 착지 칸을 모두 노란 점유 예고로 표시한다. F와 필살기 게이지는 복원하지 않는다. 이동술도 매번 행동 한 번을 소비하며 별도 충전·쿨다운은 만들지 않는다. 보유 이동술은 동시에 **하나**다.

| 이동술 | 1레벨 | 2레벨 | 3레벨 | 역할과 제한 |
|---|---|---|---|---|
| 나이트 | 체스 L자 8곳 | 착지 칸과 상하좌우 4칸 불길 제거 추가 | 이동술 뒤 다음 공격 첫 직격 +1 저장 추가 | 중간 벽·적을 넘지만 착지 칸은 빈 이동 가능 칸. 포위 탈출 |
| 비숍 | 대각선 최대 3칸, 이동 경로 불길 제거 | 최대 4칸 | 최대 5칸 | 불길 정리와 대각선 재배치. 중간 벽·적은 통과 불가 |
| 룩 | 직선 최대 4칸 | 최대 5칸 | 최대 6칸 | 긴 통로에서 적 사선 이탈. 중간 벽·적 통과·불길 제거 없음 |

이동 패턴과 나이트의 불길 제거는 유지하며 **교체 시 기존 레벨 보존, 나이트 3레벨 저장 피해를 첫 직격으로 한정**했다. 비숍·룩이 나이트보다 무조건 상위가 아니며, 대각선/직선 통로와 포위 탈출의 차이로 고른다.

비숍·룩의 한 칸 착지는 기본 이동으로 처리한다. 그 한 칸에는 이동술 착지 효과나 경로 불길 제거를 주지 않는다. 노란 색은 선택 가능이라는 뜻이지 안전하다는 뜻이 아니다. 다음 적 공격·투사체·불길 예고를 함께 보여줘야 한다.

플레이어가 이동술로 제단에 착지하면 기존처럼 즉시 획득 후 적 턴을 진행한다. 왕의 차례만 예외적인 무료 기본 이동이며 이동술 또는 추가 공격으로 이어지지 않는다.

## 9. 적용·검증 순서

| 단계 | 분류 | 작업 | 목적 / 위험 / 더 단순한 대안 |
|---|---|---|---|
| 1 | Core | 백 보존, 무효 카드 제외, 이동 숙련 보존, 충돌 처치 통지, 봉쇄 중복 제거 | 선택 손실과 인과관계 오류 제거. 전투 피해를 먼저 올리는 것보다 위험이 작음 |
| 2 | Core | 유리 심장·예리한 마력 역할 분리, 특성 완성 분기, 과충전 두 번째 중첩, 회복 정수화 | 의미 있는 선택. 초과 피해 전달이 복잡하면 우선 유리 심장 비용 -2와 예리한 마력 조건부 효과만 시험 |
| 3 | Core | 범위 중복 제한과 넉백 처치 봉쇄 | 밀집 관통 폭주 억제·원샷 넉백의 역할 유지. 관통만 약하게 만들면 클리어 불가능해질 위험이 있으므로 네 빌드를 함께 비교 |
| 4 | Supporting | 최소 등급 추첨 수정, 미획득 전용 후보 우선 여부 시험 | 필수 부품과 희귀 최종 변형 구분. 보상 횟수·화폐 추가는 하지 않음 |
| 5 | Feedback | 카드의 실제 선택 후 수치, 발동 조건·행동당 한도·체력 비용, 공격/착지의 범위·봉쇄 대상 예고 | 플레이어가 다음 반격을 계산하도록 지원. 새 장식·애니메이션보다 우선 |

### 자동 검증 필수 사례

* 주기 강화와 무관한 강화 후에도 백의 미사용 결과가 유지된다. 추가 시전은 백을 소비하지 않는다.
* 각 특성의 빈도 최대 강화 후 16웨이브 특성 완성을 얻어도 실제 효과가 증가한다.
* 나이트 3 → 비숍 3 → 룩 3에서 레벨 손실·3레벨 연마 무효 후보가 없다.
* 관통 파동 중심 세 곳에 같은 적이 포함돼도 해당 효과는 한 번만 피해를 준다. 다른 효과는 합산하고 재폭발은 없다.
* 직격·충돌·범위로 사망한 경우를 분리하고 점유·처치 보상·다음 관통 대상을 검사한다.
* 원샷 넉백, 이동 불가 넉백, 룩 대상 넉백에서 봉쇄할 다른 대상이 있으면 봉쇄가 낭비되지 않는다.
* 성벽의 룩이 범위 피해·봉쇄를 받되 이동 넉백은 받지 않는다. 피해 판정에 바닥 이동 가능 조건을 잘못 재사용하지 않는다.
* 유리 심장의 초과 피해 0 / 1 / 2 / 3, 주변 후보 0 / 1 / 여러 명, 후보 동률을 검사한다. 전달은 최대 2·한 번이다.
* 나이트 3·기습 문장·과잉 저장기의 같은/다른 출처 저장, 헛발, 웨이브 전환을 검사한다.
* 회복 호흡 최대 체력 7 / 9 / 10 / 13에서 각 중첩의 회복량을 검사한다.
* 보호가 겹친 불길·일반 피해에서 0피해인 뒤의 보호가 소모되지 않는다.
* 16웨이브 희귀 후보 소진 후에도 일반 유물이 대신 나오지 않는다.
* 위 네 경로가 일반 6 / 상급 4 / 유물 4슬롯을 넘지 않는다.

### 실제 플레이테스트

우선 동일한 맵·웨이브 조합·적 체력으로 ① 핵심 부품만 갖춘 빌드 ② 위 최종 예시 ③ 전설 포함 고점 빌드를 비교한다. 전설 없는 런의 후반 진행 가능성이 먼저다. 자동 수치 비교와 인간 플레이를 분리하고 승률은 실제 런 결과로만 보고한다.

웨이브 4·8·10·12·16·20에서 생존 체력, 플레이어 행동 수, 행동당 처치 수, 서로 다른 봉쇄 대상 수, 피한 피해, 이동술 사용 수를 기록한다. 관통은 밀집/분산 배치, 넉백은 통로/벽 없는 공간/룩 혼합 배치를 각각 확인한다. 빌드가 특정 조건에서 약한 것과 모든 배치에서 약한 것을 구분한다.

영향이 큰 위험은 범위 중복 제한과 예리한 마력 조건 변경으로 후반 전체 화력이 내려가는 점이다. 위 예시의 조건부 범위·봉쇄 보완을 함께 검증해야 한다. 반대로 제안된 데미지 최종형의 주변 피해 3은 원샷 문턱을 넘으므로, 발동하지 않는 턴과 분산 배치가 실제 약점으로 남는지 확인한다.

**검증 한계:** 단위 픽스처와 Unity 실제 입력·AI·성장 경로의 자동 런을 구분한다. 강제 체력·보상·적 처치를 사용하는 픽스처는 승률에 넣지 않는다. 자동 승률은 한 휴리스틱 플레이 정책의 결과이며 인간의 숙련도·선택률·재미를 검증하지 않는다. 일부 턴 제한 런은 봇의 회피 반복을 뜻할 수 있어 사망과 별도로 기록한다. 최종 밸런스가 확정됐다는 의미가 아니다.
