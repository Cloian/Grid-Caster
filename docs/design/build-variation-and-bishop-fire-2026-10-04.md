# 비숍 불길과 빌드 편향 추첨 — 2026-10-04

사용자가 보고한 경로 밖 불길과 반복되는 증강·웨이브 구성을 수정했다. 확인한 범위는 시작 공격 특성 하나 유지, 현재 특성·보유 이동술 우대, 다른 이동술·생존·범용 후보 등장, 적 해금 순서와 10·20웨이브 유지다. 카메라 흔들림은 추가 판단을 기다리며 이번에 변경하지 않았다.

## 불길

기존 코드는 비숍의 실제 경로 외에 플레이어 대각선 인접 칸에 차단 불길 하나를 추가했다. 실제 씬에서 `(2,2) → (3,3)` 이동 뒤 `(4,4)`에 새 불길이 생기는 것을 [수정 전 검사](../verification/bishop-off-path-before-2026-10-04.txt)로 재현했다. 이 추가 규칙을 제거해 출발점·경로·도착점에만 불길을 만든다. 위험 미리보기 설명도 수정했다. 불길의 3턴 수명·진입 피해·공격 경로 정화는 유지한다.

## 증강

시작 선택과 일반 보상 모두 중복 없는 가중 추첨 세 장이다. 전용 확정 슬롯, 미보유 전용 부품 우선 선택, 2웨이브 나이트 확정 슬롯을 제거했다. 비숍·룩 이동술 습득은 일반 풀로 옮겨 시작부터 다른 이동술을 선택할 수 있다. 총 강화 수는 25종 그대로이며 일반 18종·상급 7종이다.

| 조건 | 추첨 가중치 |
| --- | --- |
| 일반 기본 | 1 |
| 현재 특성 전용 | ×3 |
| 이미 선택한 강화의 다음 중첩 | 추가 ×1.5 |
| 보유 이동술 연마·구속 착지 | 추가 ×2 |
| 이동술 미보유 시 습득 카드 | ×1.5 |
| 해금된 상급 기본 | 2 |

이는 각 카드의 최종 등장 확률이 아니다. 세 장을 뽑으며 선택된 후보를 제거하므로 풀·중첩·보유 상태에 따라 확률이 달라진다. 일반 보상에 전용 카드가 하나도 없는 조합도 가능하다. 효과가 없는 다른 공격 특성 전용, 최대 중첩, 최대 레벨 연마, 같은 이동술 재습득은 제외한다. 이동술은 계속 하나만 보유하며 교체해도 레벨을 유지한다.

유물 획득 보상은 해금 단계 이하 미보유 상급과 일반 후보를 섞는다. 상급이 남아 있으면 무작위 상급 최소 한 장을 포함해 유물 보상의 품질을 지키고, 나머지 두 장은 전체 풀에서 가중 추첨한다. 단계별 세 장을 그대로 내놓지 않는다. 미래 상급 조기 해금은 없으며 같은 이동술 습득/연마 결과는 다른 ID여도 한 카드로 취급한다. 보상 시점·횟수는 유지한다.

## 웨이브

`WaveTemplateCatalog.Get`은 기준 조합, `Roll`은 실제 추첨이다. 10·20웨이브를 제외하면 기준 조합에서 기존 유형 간 한 마리를 교환한 후보와 원래 조합 중 하나를 고른다. 각 기존 유형 최소 한 마리, 총 마릿수, 능력치, 난이도 단계, 유물 시점과 기믹 해금은 유지한다. 한 유형만 등장하는 1웨이브는 배치만 변주한다.

지상 외곽 시작점과 적 유형의 배치 순서도 무작위로 바꾼다. 플레이어 최소 거리·빈 칸·성벽 룩 규칙은 유지한다. 10·20웨이브의 조합과 지상 배치 순서는 기존 기준을 유지한다. 성벽 룩의 시작점은 기존처럼 무작위다.

## 목적·트레이드오프·검증

기존 빌드에 투자한 선택이 후속 후보에 반영되면서, 다른 이동술이나 생존 카드로 방향을 바꿀 기회를 만든다. 새 효과를 늘리는 대신 기존 후보의 추첨 정책을 바꿨다. 전용 부품이나 조기 이동술이 반드시 나온다는 보장은 사라졌으므로 플레이테스트에서는 빌드 완성 실패의 답답함과 새로운 조합 선택을 함께 확인해야 한다. 더 단순한 대안은 일반 보상만 추첨하는 것이지만, 이번에는 사용자 요청대로 시작·상급 보상과 웨이브도 변주했다.

- [빌드·웨이브 검사 84조건](../verification/build-variation-2026-10-04.txt) 통과. 네 특성 각각 일반 추첨 3,000회, 보유 강화/이동술 추첨 3,000회, 상급 단계·이동술 레벨 조합별 총 3,600회, 웨이브 20개 총 6,000회와 실제 스폰 25회 검사.
