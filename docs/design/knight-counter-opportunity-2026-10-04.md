# 나이트 착지 후 반격 기회 — 2026-10-04

사용자가 합의한 공통 방향인 ‘특수 공격을 읽고 대응한 뒤 짧은 공격 기회를 얻는다’를 나이트에 먼저 적용했다. 현재 나이트만 대상이며 비숍·룩의 행동이나 피격 규칙을 바꾸지 않았다.

| 검토 항목 | 결정 |
| --- | --- |
| Feature / 분류 | 착지 후 한 행동의 인접 첫 직격 +1 / Core |
| Purpose | 도망·원거리 공격 반복 사이에 가까이 남아 공격할 이유를 만든다. |
| Player Experience | 착지 뒤 주변 적과 다음 턴 위험을 보고 반격과 이탈을 고른다. |
| Core Fun Contribution | 한 번의 강한 특수 행동이 끝난 시점을 읽어 위치와 준비한 특성 공격을 활용한다. |
| Risk | 추가 피해를 받으려고 십자 피해를 일부러 맞는 선택이 우세해지거나 근접 공격만 정답이 될 수 있다. 실제 체감과 난이도는 사람 플레이로 확인한다. |
| Simpler Alternative | 기존 준비 턴 공개만 유지한다. 이번에는 공격을 선택할 명시적인 보상을 검증하기 위해 +1을 붙였다. |

## 규칙

1. 성공한 L자 도약의 착지 연출과 십자 피해 처리가 끝난 뒤 취약 상태가 열린다. 도약 중이나 실패한 도약에는 열리지 않는다.
2. 다음 플레이어 행동에서 나이트와 체비쇼프 거리 1, 즉 상하좌우·대각선으로 한 칸 인접하여 공격하면 첫 직격에 피해 +1을 준다. 일반 공격과 준비한 특성 공격 모두 적용한다.
3. 보너스는 공격 확정 시 대상과 함께 저장하며 한 행동의 첫 시전·첫 직격에만 더한다. 추가 시전·다음 관통 대상·범위·충돌 피해에 따로 반복하지 않는다. 강화와 유물이 가진 다른 피해 효과는 기존 규칙을 따른다.
4. 이동·이동술·다른 적 공격·빗나감도 그 기회를 끝낸다. 선택·취소·유효하지 않은 입력·검사·일시정지만으로는 소모되지 않는다. 실시간 제한은 없다.
5. 착지 십자 피해는 취소하거나 회복하지 않는다. 공격은 기존 행동 한 번을 소비하고, 추가 시전이 끝난 뒤 적은 한 번 행동한다. 일반 적중 행동 충전은 한 번, 특성 공격 충전은 없다.
6. 이름표에 `취약`을 표시하며 마우스를 올리면 조건과 다음 턴 위험을 함께 설명한다. 도약 간격 2턴의 실제 웨이브와 1턴 간격의 독립 패턴 회귀 씬을 모두 지원한다.

추가 버튼·자원·별도 반격 입력은 없다. 보너스 피해는 기존 공격의 타격 피드백을 그대로 사용한다. 가까이 서 있다고 자동 공격하지 않는다.

## 검증

Unity 6000.4.0f1 격리 복사본에서 실제 SampleScene의 이동·공격 API와 착지 콜백을 실행했다. 정상 런의 승률·길이·사람의 재미를 검증한 결과는 아니다. 공개 Web 링크는 갱신하지 않았다.

- [나이트 반격 검사 198조건](../verification/knight-counter-2026-10-04.txt): 8방향의 보너스, 기존 착지 피해, 행동에 따른 기회 소모, 취소·검사 중 유지, 네 특성 공격의 중복 방지, 봉쇄, 처치·점유 해제, 신규 스폰·도약 실패, PC 상태 문구 높이를 검증한다.
- [체스 전투·UI 회귀](../verification/knight-counter-chess-2026-10-04.txt): 기존 670조건 통과.
- [타격 피드백 회귀 43조건](../verification/knight-counter-feedback-2026-10-04.txt): 기존 피격·섬광·처치 잔상·넉백 연출·행동 간격·음량 검사 통과.

[소스 해시](../verification/knight-counter-source-2026-10-04.json)는 명시한 관련 파일만 식별한다. 기존 회귀 뒤 설명 문구의 줄바꿈·길이를 정리했으며, 최종 반격 검사에서 두 도약 간격의 문구 높이를 확인했다. 재현은 씬을 저장하고 Play를 종료한 뒤 `Tools > Playtest > Validate Knight Counter Opportunity`, 또는 배치 실행의 `-executeMethod KnightCounterValidation.RunBatch`를 사용한다.

[첫 실행의 실패 기록](../verification/knight-counter-before-death-assert-2026-10-04.txt)은 실제 처치 후 파괴된 Unity 객체의 `IsDead`를 읽던 검사 오류다. 실제 피해 2와 사망은 발생했으며, 사망 이벤트에서 체력 0을 확인하고 턴 종료 후 점유 해제를 검사하도록 수정했다.

사람 플레이에서는 ‘다음 행동을 위해 붙어 있어도 되나’, ‘다른 적 때문에 기회를 버릴 만한가’, ‘피격 없이 얻은 반격과 일부러 맞는 반격 중 무엇을 고르나’를 관찰한다. 대피 반복 감소나 재미 개선은 이 규칙 검사만으로 확정하지 않는다.
