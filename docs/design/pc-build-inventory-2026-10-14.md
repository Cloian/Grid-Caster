# PC 보드 중심 화면과 빌드 확인 창

2026-10-14 요청: 보드가 작고 상시 강화·유물 목록이 시선을 빼앗으므로, 보유 항목은 별도 UI로 확인한다.

- 평소 좌우 보유 강화·유물 목록은 숨기고 보드 위 오른쪽에 `빌드 · B` 버튼만 둔다.
- 클릭 또는 B로 보유 빌드 창을 열며 강화·이동술·유물·보급·현재 제단을 함께 확인한다. 각 항목의 상세 설명을 계속 사용할 수 있다.
- B, Esc, 닫기, 창 바깥 클릭으로 닫는다. 상세 설명이 열렸으면 Esc는 설명부터 닫는다.
- 검사 중 턴과 경과 시간은 진행하지 않고, 닫은 뒤 기존 이동·공격 선택을 보존한다. 닫기 클릭의 보드 전달도 차단한다.
- 제단이 있는 웨이브에는 버튼에 제단 수를 표시한다. 두 제단의 이름·등급·효과는 시작부터 확인 가능하며 획득 전 불리한 효과도 상세 설명으로 공개한다.
- PC 카메라는 상단 78·하단 152 기준 픽셀의 HUD 공간과 좌우 최소 여백을 제외한 최대 정사각형에 전체 보드를 맞춘다. 1920×1080에서 보드 변 길이는 800→850이며 높이가 넉넉한 창에서는 더 확대한다.
- 유물 교체 창은 PC 중앙에 표시한다. 시작·웨이브 강화 선택 흐름은 유지한다.
- 기존 모바일 전용 접이식 목록은 유지한다. 창 폭만으로 모바일로 전환하지 않는다.
- 기존 씬·Sprite·Animator 참조와 게임 규칙은 변경하지 않는다. 런타임 UI 생성 코드를 수정하므로 추가 Inspector 설정이 필요하지 않다.
- 이번 작업에서 공개 웹 링크는 갱신하지 않는다.
