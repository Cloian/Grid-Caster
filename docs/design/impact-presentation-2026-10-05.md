# 잔여 마력 파편과 공격 성과 피드백 — 2026-10-05

## 적용한 연출

- 준비된 데미지 강화 F 공격은 따뜻한 밝은 색, 약간 두꺼운 탄과 짧은 꼬리로 구분한다. 직격 위치에서 원래 탄이 사라진다.
- 직격 위치에 약 25ms 동안 작은 파편의 빛이 모이고, 남은 약 55ms 동안 실제 주변 피해 대상에게 갈라져 날아간다. 작은 굽은 경로와 얇은 꼬리를 사용한다. 관통은 기존 직선 진행을 유지한다.
- 파편 끝점은 적중 당시 위치로 고정한다. 게임 규칙을 가진 유도탄·연쇄 공격이 아니며, 주변 대상이 없어도 직격 섬광은 표시한다. 직격 대상의 생존·처치 여부와 무관하게 주변 피해 대상이 있으면 파편이 나온다.
- 주변 생존 적은 파편 도착 때 붉은 피격 섬광·반동을 시작한다. 주변 처치는 즉시 점유를 해제하고 비전투 복사본을 잠깐 유지한 뒤 도착 때 흰 섬광·축소 잔상을 시작한다.
- 일반 명중의 흰 섬광은 3픽셀 길이, 데미지 강화 중심은 5픽셀 길이, 처치는 따뜻한 6픽셀 길이로 구분한다. 한 행동의 추가 처치는 최대 8픽셀까지 강조한다. 처치 잔상은 시작 25ms에 흰색을 보여준다.
- 일반 명중의 음높이는 유지하고, 강화 중심은 조금 낮게, 처치는 더 낮게 재생한다. 동시 주변 반응은 소리 하나로 합치고 기존 대비 55% 세기로 낸다. 처치음은 겹친 일반 명중음보다 우선하되 전체 세 전투 음성과 별도 플레이어 피격 음성을 유지한다. 다음 일반 발사는 원래 음높이로 복원한다.

피해·사망·점유·충전·유물 보상은 기존 시점과 규칙으로 확정한다. 애니메이션이 피해량·피해 대상·행동 수를 결정하지 않는다. 기존 마지막 명중 후 80ms 회복 시간 안에 파편이 도착하며, 별도 턴 대기는 추가하지 않는다. 카메라 흔들림은 기존 2 화면 픽셀·70ms를 유지한다.

## 한 행동당 결과 하나

모든 추가 시전을 마친 공격에서 가장 중요한 결과 하나를 기존 행동 안내 한 줄에 약 0.65초 표시한다. 기본 안내는 시간이 끝나거나 다음 선택을 시작하면 다시 보인다. 적을 가리켜 위험을 확인하는 설명과 종료 안내는 우선한다.

1. 두 체 이상 처치: `2체 처치` / `3체 처치` 등. 직격·주변·충돌 피해로 실제 죽은 적을 중복 없이 센다.
2. 위 조건이 없고 실제 나이트 반격 적중: `반격 +1`.
3. 위 조건이 없고 실제 넉백 경로가 벽·점유로 막힘: `충돌`. 밀기 자체가 적용되지 않는 성벽 룩은 이 문구에서 제외한다.

평범한 명중·단일 처치에는 결과 문구를 띄우지 않는다. 처치는 섬광·잔상·소리로 구분한다. 결과 표시는 추가 피해나 보상이 아니며 적 턴의 피해를 이전 공격 성과에 더하지 않는다. 일시정지는 파편·대기 중 반응·결과 표시 시간을 멈추고, 새 런/전투 초기화는 파편·대기 소리·결과 상태를 지운다.

## Unity 설정과 확인 방법

새 GameObject·컴포넌트·Inspector 할당·태그·레이어·Tilemap·Collider 수동 설정은 없다. 기존 SampleScene의 런타임 `CombatFeedback`가 비전투 Sprite를 만들고 기존 HUD와 효과음을 사용한다. 모든 파편과 섬광은 Point 필터·32 PPU 절차 스프라이트를 공유한다. 새 패키지·음원·몬스터 Prefab·씬 YAML 변경은 없다.

SampleScene에서 데미지 강화를 선택하고 일반 A 공격으로 충전한 뒤, 적이 모인 곳을 F로 공격한다. 중심에서 탄이 멈춘 뒤 작은 파편이 주변으로 갈라지고, 파편 도착 때 주변 적이 반응해야 한다. 나이트가 착지한 다음 인접 상태에서 A/F로 공격하면 `반격 +1`, 넉백 F를 막힌 경로로 쏘면 `충돌`, 한 공격으로 여러 적을 죽이면 `N체 처치`가 잠깐 보인다. 관통·일반 A는 파편을 만들지 않는다.

자동 검증은 Unity 6000.4.0f1의 격리 복사본에서 실제 SampleScene을 실행한다. 검사기는 `Tools > Playtest > Validate Impact Presentation` 또는 `-executeMethod ImpactPresentationValidation.RunBatch`로 실행하며 비동기 Play 검증이므로 `-quit`을 붙이지 않는다. 결과와 실제 URP 보드 렌더는 `docs/verification/impact-presentation-*`, `docs/verification/captures/residual-magic-*`에 보관한다. 보드 렌더는 Screen Space Overlay HUD를 포함하지 않는다. HUD 문구는 실제 Text 컴포넌트에서 별도로 검증한다.

검증은 기능과 회귀 검사이며 사람의 재미·멀미·음색 선호도를 측정한 결과가 아니다. 공개 Web은 갱신하지 않았다.

[소스 해시](../verification/impact-presentation-source-2026-10-05.json)의 관련 파일은 격리 검사본과 바이트가 같다.

검사 과정에서 겹친 명중음이 처치음을 생략하는 실제 문제를 수정했다. 사망 후 삭제된 컴포넌트의 상태를 읽던 초기 검사와, 이전 효과음의 재생·실시간 간격을 격리하지 않은 음높이 검사를 수정했다. 수정 전 결과도 `impact-presentation-before-*` 및 `impact-presentation-first-fixture-failure-*`로 보관했다.
