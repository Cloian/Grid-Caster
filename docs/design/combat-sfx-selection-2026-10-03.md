# 전투 효과음 청취 선택 — 2026-10-03

사용자가 직접 듣고 선택한 기준은 다음과 같다.

- 마법 발사·비행: M4. 다만 더 부드러운 레이저 느낌과 조금 느린 소리를 요청했다.
- 생물 명중: S1.
- 단단한 대상 명중: H4.
- 플레이어 피격: P4.
- 기갑기마 착지: K5.
- 불길 펼침: F2.
- 쇠뇌 장전·발사: 보류. 사용자는 소리가 너무 많아지는 부담을 언급했다.

[선택 음원과 수정안](../../Art/Audio/SelectedCombatSFX-v3/README.md)에 묶었다.
M4 수정안은 원본 약 0.23초에서 약 0.42초로 늘리고 시작과 고역을 완화했다. 사용자가 게임에 먼저 적용해 볼 것을 요청했다.
다른 다섯 음원은 선택한 v2 파일을 그대로 복사했다.

2026-10-04 선택한 여섯 음원을 Unity 전투에 연결했다. ESC 메뉴의 효과음·음악 볼륨, 설정 저장과 동시 재생 제한을 적용했다.
착지·불길은 낮게 재생하며 같은 종류의 환경음은 동시에 하나만 재생한다. 플레이어 피격은 별도 음성으로 확보한다.
추가 후보를 다시 대량 제작하기보다 선택한 여섯 종류를 기준으로 정리한다.

[적용 범위와 검증](combat-audio-integration-2026-10-04.md)을 확인한다. 임시 프로젝트 복사본의 Unity 실행 검사는 통과했으며, 원본 열린 Editor에서 직접 청취한 검증은 아니다.
