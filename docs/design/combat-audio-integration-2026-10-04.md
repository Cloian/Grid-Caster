# 선택 전투 효과음 적용 — 2026-10-04

사용자의 “일단 적용” 요청에 따라 선택 음원 여섯 개를 게임 전투와 기존 ESC 일시정지 메뉴에 연결했다. 쇠뇌 장전·발사음은 보류한다.

| 소리 | 판정 / 재생 시점 | 선택 | 종류별 상대 음량 |
| --- | --- | --- | --- |
| 마법 발사 | 실제 플레이어 시전마다 투사체 생성 성공 직후. 관통 내부 구간에서는 재발사하지 않음 | M4 부드러운 수정안 | 0.72 |
| 생물 명중 | 박쥐·뱀 유형의 HP가 실제 감소할 때 | S1 | 0.78 |
| 단단한 대상 명중 | 나이트·비숍·룩의 HP가 실제 감소할 때 | H4 | 0.60 |
| 플레이어 피격 | 성장 효과의 피해 보정 후 HP가 실제 감소할 때. 불길과 근접·쇠뇌 피해에 공통 사용 | P4 | 0.90 |
| 나이트 착지 | 도약 이동 연출의 실제 착지 콜백에서 한 번 | K5 | 0.50 |
| 불길 펼침 | 비숍의 유효한 이동/불길 행동마다 한 번. 불길 칸마다 재생하지 않음 | F2 | 0.45 |

종류별 상대 음량에 사용자의 효과음 볼륨을 곱한다. 선택한 WAV의 파형·피치·길이는 유지했다. 치명타에도 명중음을 한 번 재생하며, 0 피해와 이미 죽은 대상에는 재생하지 않는다. 기존 막힌 이동 알림도 같은 효과음 볼륨과 재생 제한을 따른다.

## 볼륨 설정

ESC 메뉴에서 효과음·음악을 독립적으로 조절한다. 첫 실행 기본값은 효과음 60%, 음악 50%이며, 기존 BGM의 0.5 기본 음량을 유지한다. 0%는 음소거다. 슬라이더 드래그, 5% 단위 −·+ 버튼, 선택된 슬라이더에서 1% 단위 좌우 방향키를 제공한다. ESC를 열면 효과음 슬라이더에 포커스한다.

`GridCaster.Audio.SfxVolume`, `GridCaster.Audio.MusicVolume` PlayerPrefs에 저장한다. 변경은 재생 중인 음원에도 바로 반영하며 메뉴 닫기, 앱 일시정지/종료에서 저장한다. 런 재시작에도 유지한다. 시작 선택창/보드 옆 패널보다 ESC 메뉴가 위에 표시되도록 전체 Canvas의 마지막 자식으로 배치한다. 기존 사망·클리어 후 ESC 전장 복기 규칙은 유지한다.

## 소리 밀도와 임포트

일반 효과는 최대 세 음성, 플레이어 피격은 별도 한 음성이다. 같은 착지·불길은 동시에 하나만 재생한다. 재생 간격은 생물·단단한 명중 35ms, 피격·막힌 이동 80ms, 착지 120ms, 불길 150ms다. 발사는 별도 간격 제한을 두지 않되 일반 음성 상한을 따른다. 일반 음성이 가득 차면 명중·발사는 오래된 환경음을 대체할 수 있으며, 환경음으로 중요한 전투 소리를 끊지 않는다.

`Assets/Resources/CombatSFX/`의 여섯 파일은 선택 원본과 SHA-256이 같다. 48kHz 16-bit PCM Mono 원본이며 Unity에서 PCM / Decompress On Load / Preload로 임포트한다. 이미 Mono이므로 강제 Mono 변환에 따른 정규화를 하지 않는다. 설정은 `CombatAudioSetupTool`의 AudioImporter API로 생성했으며 GUID를 보존했다. 씬에 수동 연결할 추가 참조는 없고 HUD 초기화에서 오디오와 설정 UI를 구성한다.

## 검증과 한계

[검사 기록](../verification/combat-audio-20261004-000338.txt): Unity 6000.4.0f1 배치 Play Mode에서 현재 Assets·Packages·ProjectSettings의 임시 복사본과 SampleScene으로 검사했다. 원본 열린 Editor는 자동화 연결이 다른 프로젝트를 가리키고 UI 제어가 응답하지 않아 직접 Play/청취를 확인하지 못했다. 임포트 설정은 복사본 Editor에서 생성한 뒤 동일 GUID를 확인해 원본 여섯 메타에 반영했다. 원본 소스와 음원에는 구현이 반영되어 있다.

검사 항목은 실제 플레이어 발사/적중과 정확히 한 번의 월드 턴, 재질별 명중, 치명타·0 피해, 착지 콜백, 불길 행동당 재생, HP 감소, 20개 동시 불길의 재생 제한, 피격용 음성 확보, 슬라이더 GraphicRaycaster/포인터/방향키, 활성 음원의 즉시 음소거, 씬 재시작 후 설정 유지와 사망 복기 입력 잠금이다.

최종 실행 검사는 통과했다. 초기 임시 프로젝트의 Unity 검색 인덱싱 예외, 오디오 임포터 API 수정, 메뉴 표시 순서/초기 Canvas 갱신과 검사 좌표 수정 과정은 임시 로그에 남겼다. 자동 검사 결과를 사람의 청취 선호도, 플레이 재미나 일반 전투 완주 결과로 해석하지 않는다. 음악과의 실제 청취 밸런스, 최종 음색 선호와 모바일 화면의 시각 검수는 추가 확인 대상이다. 공개 Web 빌드/배포는 갱신하지 않았다.

다시 검사하려면 원본 SampleScene에서 Play를 종료하고 `Tools > Playtest > Validate Combat Audio and Volume`을 실행한다. 배치 실행은 `-executeMethod CombatAudioValidation.RunBatch`로 동일 검사를 수행한다. 출처와 사용 소재는 [음원 크레딧](../../Art/Audio/SelectedCombatSFX-v3/CREDITS.md)에 기록했다.
