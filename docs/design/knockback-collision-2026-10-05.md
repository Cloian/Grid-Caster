# 넉백 충돌과 충격 확산 — 2026-10-05

사용자는 넉백의 벽·다른 캐릭터 충돌 피해를 원했고, 인접 타일의 적도 미는 강화와 봉쇄의 분리를 선택했다. 기본 충돌 피해를 적용하고 기존 `긴 충격`의 피해·거리 증가를 `충격 확산`으로 교체했다. 내부 ID `long_impact`는 유지한다.

| Feature / 분류 | 넉백의 실제 충돌 피해와 인접 방사형 밀기 강화 / Core |
| Purpose | 벽·적의 뒤쪽 배치가 공격 대상 선택의 보상이 되게 한다. |

| Core Fun Contribution | 공격선과 적 뒤의 공간을 함께 읽고, 밀기와 봉쇄 중 무엇을 먼저 성장시킬지 고른다. |

## 규칙

- 기본 넉백: 생존한 직접 대상을 공격 방향으로 1칸 민다. 벽 충돌은 밀던 적 피해 1, 적 충돌은 양쪽 피해 1. 이 피해는 직격 피해와 별개다.
- 밀기 거리 강화가 있으면 가능한 칸까지 이동한 뒤 막힌 곳에서 충돌한다. 빈 칸으로 정상 이동한 경우 추가 피해는 없다. 다른 적을 연쇄적으로 밀지는 않는다.
- 플레이어가 막는 경우 이동만 막고 충돌 피해는 없다. 성벽 룩은 기본 밀기 면역이라 가상의 충돌 피해를 받지 않는다. 다른 적이 룩과 실제 충돌하면 룩도 충돌 상대 피해를 받는다.
- 충격 확산 Lv.1: 원래 적중 지점 주변 8칸의 살아 있는 이동 가능한 적을 중심에서 바깥으로 각각 1칸 민다. 플레이어·룩·직접 대상은 제외한다. 중심 직접 대상이 직격으로 죽어도 주변 밀기는 적용된다. 주변에 있다는 이유만으로 피해를 주지 않는다.
- 직접 대상의 밀기를 먼저 처리한 후 발사 당시가 아닌 **적중 당시**의 주변 대상 목록을 처리한다. 직접 대상의 충돌 상대가 나중에 밀려나도 직접 대상을 다시 밀지 않는다.
- 같은 적은 한 공격 행동 동안 충돌 피해를 한 번만 받는다. 다음 행동에서는 다시 피해를 받을 수 있다. 충돌 피해에 철벽 못·도미노 문장·특성 완성의 조건부 추가 피해를 합산한다. 각 밀기의 첫 실제 적 충돌에 도미노 문장·특성 완성을 적용한다.
- 충격 고정은 추가 피해를 제거하고 봉쇄만 담당한다. Lv.1은 생존 직접 대상의 다음 적 행동 2회, Lv.2는 직접 밀기의 첫 충돌 상대 행동 1회도 막는다. 파성추의 기존 직접 대상·첫 충돌 상대 봉쇄도 유지한다. 주변 밀기 전체를 봉쇄하지 않는다.
- 직접 밀기의 충돌 처치는 기존 직접 처치 보상을 유지한다. 주변 밀기로 발생한 처치는 추가 직접 처치 보상·충전·별도 플레이어 행동을 만들지 않는다.

## 연출과 판정

타일 위치·피해·사망·점유 해제는 즉시 처리한다. 최대 110ms의 기존 이동 복사체로 밀리는 모습을 보여주며, 한 칸 이상 이동 후 충돌한 경우 충돌 섬광·소리를 도착 시점에 맞춘다. 충돌로 사망한 적의 독립 잔상도 원래 위치에서 도착 위치까지 이동한 뒤 축소·소멸한다. 이동 연출이 끝나기 전에는 적 턴을 시작하지 않는다. 카메라 흔들림의 강도와 시간은 이번 변경에서 늘리지 않았다.

F 조준에서 충격 확산의 주변 칸을 기존 범위 색으로 표시한다. 플레이어·벽 칸은 제외하며, 표시는 효과 후보 범위다. 실제 피해는 충돌할 때만 발생한다.
