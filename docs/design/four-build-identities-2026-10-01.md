# 네 빌드 분리 실험 — 2026-10-01

2026-10-05 사용자 선택으로 데미지 강화의 전용 초과 전달을 [적중 주변 범위 공격](damage-boost-splash-2026-10-05.md)으로 교체했다. 아래 피해 빌드의 초과 전달 설계·검증은 변경 전 기록이며 현재 규칙은 `GrowthAndRelics.md`를 따른다.

사용자가 승인한 ‘네 시작 특성은 유지하되 겹치는 부가 효과를 덜어내고 네 가지 플레이 방식으로 발전시킨다’는 가설의 첫 구현이다. 현재 목록·정확한 수치는 [GrowthAndRelics.md](../../GrowthAndRelics.md)를 따른다. 9월 30일의 수치 문서는 변경 전 기록이다.

## 가설과 반증 조건

H1: 모든 빌드가 주변 폭발·다수 봉쇄·첫 처치 회복을 함께 얻기보다, 공격 순서/직선 배치/처치 대상/충돌 지점을 다르게 고민할 때 선택의 의미가 커진다.

H2: 범용 효과를 제거하는 만큼 각 빌드의 고유 처리력을 보완하면 전설 없이도 20웨이브를 진행할 수 있다. 단순히 보상 수나 모든 빌드의 힘을 줄이는 실험이 아니다.

H3: 선택 카드는 핵심 효과·발동 확률만 보여 주고 상세에 예외를 분리하면 신규 규칙을 이해할 수 있다.

반증: 고유 부품을 골라도 공격·이동 판단이 같음 / 특정 전설 없이는 진행 불가 / 반복 회피·무효 공격으로 턴 제한에 도달 / 초과 피해가 생기지 않아 피해 빌드 보상이 사실상 무효 / 새 설명으로 비용·레벨·대상 조건을 오해함. 자동 검사만으로 재미나 이해도를 확정하지 않는다.

## 변경

| 빌드 | 덜어낸 요소 | 강화한 고유 역할 |
|---|---|---|
| 더블 캐스트 | 메아리 추가 관통, 반향 압박의 주변 봉쇄 | 추가 시전 피해가 중첩마다 증가, 일반 강화 ‘회전 영창’으로 재조준. 회전 거울은 중복 보유 시 추가 피해를 주어 무효 보상이 되지 않음 |
| 관통 | 추가 적중 주변 파동 | ‘관통 가속’은 직선의 두 번째 대상부터 직접 피해 강화. 긴 바늘/심화는 같은 공격선의 대상 수 확대 |
| 데미지 강화 | 잔광 봉쇄와 첫 적중 무료 범위 피해 | 과충전 Lv.2 직접 피해 4로 체력 3을 넘기는 문턱 생성. 실제 남은 피해만 전달하며 분배 핵은 총량을 두 대상에 나눔. 생존 적중/직접 처치는 다음 공격 저장으로 분리 |
| 넉백 | 사망한 대상 주위까지 번지는 봉쇄 | 살아남은 직접 대상과 실제 첫 충돌 상대만 봉쇄. 완성은 직격·충돌 피해 강화. 철벽 못/파성추로 이동 불가 룩 대응 유지 |

공용 연쇄 폭발을 후보·판정에서 제거한다. 폭발 순환은 특성별 ‘특성 심화’로 전환한다. 교대 과충전은 제거하고 이동 후 범위 공격은 교대의 톱니 유물 한 경로로 남긴다. 전투 재생·불멸 순환은 제거하고 첫 직접 처치 회복은 피의 매듭으로 모은다. 클리어 회복 호흡과 관통 다중 직격 봉합 바늘은 다른 조건이므로 유지한다. 제한적인 공용 구속 착지와 기습 문장은 이번 첫 실험에서 유지하며 후속 관찰 대상이다.

## 범위와 호환

* 13×13 보드, 8방향, 적 구성·체력·피해·턴 순서·불길·룩 열 공격·카메라·입력·아트는 변경하지 않는다.
* 보상 10선택, 유물 4기회, 이동술 공용·하나 보유를 유지한다.
* 일반 17→16, 상급 12→9, 유물 21종 유지. 유물 보상의 부족한 카드는 현재 단계 이하의 미보유 상급을 우선 보충하고 전용/공용 일반을 최후 보충한다. 따라서 무조건 ‘같은 단계의 상급 세 장’은 더 이상 규칙이 아니다.
* 이동술 연마 I~IV 표시를 단일 이름으로 통일한다. 코드의 단계 ID는 유지하며 현재→선택 후 실제 레벨을 표시한다.
* 재설계 항목은 기존 ID를 유지해 아이콘·연결 키를 보존한다. 역할과 다른 폭발/봉쇄 아이콘 연결은 해제해 이름 글자를 임시 표시한다. 새 최종 아이콘은 제작하지 않는다.
* 런 중 성장 저장은 구현되지 않았으므로 재시작한 새 런에 적용한다. 삭제된 ID의 효과를 숨겨서 유지하지 않는다.

## 검증 설계

1. 실제 Unity Play 규칙 fixture: 직선 밖 피해 없음, 재조준 해금, 피해 전달 총량/1회/비연쇄, 직접·충돌 대상 제한, 저장 1회, 후보 3개·최대 레벨·미래 단계 제외, 합법적 최종 빌드 산출.
2. SampleScene 실제 Canvas: 카드·상세 잘림, 클릭 대상, 입력 차단, 레벨, 제단 품질. 씬·렌더 설정은 보존.
3. 기존 체스 Play 회귀: 이동·점유·턴·투사체·불길·몬스터·웨이브.
4. 변경 전후 각 4빌드 × 동일 초기 시드 4개. 봇 판단 함수를 고정해 코드 변경 외 실험 조건을 유지한다. 같은 초기 시드여도 후보 수 변경으로 이후 RNG와 선택은 달라지므로 동일 전장 재현 실험은 아니다.
5. 전설 회피 독립 시드: 기능이 전설 유물에 종속되지 않는지 확인한다.

고정 봇은 변경 전 효과를 근사하는 일부 점수식을 포함하므로 실력 있는 인간의 선택/최적 빌드 성능을 대표하지 않는다. 메커니즘 분리 여부는 규칙 fixture로, 진행 가능성은 실제 런으로, 재미와 이해도는 별도의 사람 플레이로 판단한다. 결과는 [검증 기록](../verification/four-build-identities-2026-10-01.md)에 기록한다.

첫 변경안의 동일 초기 시드 16회에서는 더블·넉백이 0/4 클리어로 고유 처리력 보완이 부족했다. 이를 숨기지 않고 탐색 결과로 보존한다. 두 번째 변경은 회전 영창의 ‘직전과 다른 방향’ 직접 피해 +1, 충격 고정의 ‘실제 밀기 경로가 막힘’ 대상 피해 1이다. 범위 피해·주변 봉쇄를 복구하지 않고 방향 전환/충돌의 선택 가치를 보완한다.

두 번째 변경 후에도 넉백은 고정 시드 0/4, 전설 회피 독립 시드 0/8이었다. 세 번째 변경은 충격 고정의 직접 생존 대상만 봉쇄 기간을 1→2 적 행동으로 늘린 것이다. 첫 충돌 상대는 Lv.2에서 1행동, 무관한 주변 적은 계속 제외한다. 기존 몬스터의 남은 봉쇄 턴 수를 사용하며 중첩 합산 없이 최대 기간만 유지하고, 다른 봉쇄 유물은 1턴 그대로다. 공격 기회를 늘려 넉백의 직접 제어 정체성 안에서 처리력 부족을 보완한다.

최종 후보 검사에서 보충한 이동술 연마 I/II처럼 ID는 달라도 이번 효과가 같은 카드가 함께 나오는 문제를 발견했다. 현재 이동술 보유 시 연마를 하나의 선택 키로, 미보유 시 동일 이동술 습득을 하나의 키로 비교해 제외한다. 이름만 다른 같은 효과가 3택1의 선택 폭을 줄이지 않도록 미보유·Lv.1·Lv.3 모두에서 카드 요약의 의미 중복까지 검사한다.

고정 봇 전설 회피 검사에서 마지막 비숍과 반대 색을 유지하며 비숍 활보만 반복하는 두 사례를 관찰했다. 게임 정지가 아닌 봇 선택 문제로 분리하고, 공개 보드의 기본 이동 색 전환을 가산하는 선택 옵션을 추가했다. 별도 정책 32런은 턴 제한 0건이지만 원래 고정 정책 결과와 합산하지 않는다. 런타임 판정이나 적 AI는 이를 이유로 변경하지 않았다.

## 사람 플레이에서 볼 항목

최소 각 빌드 1회, 설명을 먼저 하지 않고 진행한다. 공격/이동 비중 외에 ‘왜 그 방향/대상을 골랐는지’, 재조준으로 다른 위협을 처리했는지, 관통 줄 세우기를 시도했는지, 피해 빌드가 초과 전달을 의도했는지, 넉백이 벽/충돌을 활용했는지 관찰한다. 보상에서 멈춘 이유와 선택 후 만족·혼란을 기록한다. 같은 두 보상만 반복 선택하거나 무관한 공용 효과가 주력이라면 후속 축소/조정을 검토한다. 사람 플레이 전에는 재미 가설을 검증 완료로 표시하지 않는다.
