# Grill with Docs

Before starting, read and apply both project-local skills completely:

- [Grilling](../grilling/SKILL.md)
- [Domain Modeling](../domain-modeling/SKILL.md)

Run them as one workflow. Use the grilling design-tree rounds to expose and settle every decision while domain modeling continuously checks terminology against the codebase and records resolved domain language. Update `CONTEXT.md` as terms crystallize, following the domain-modeling format. Offer an ADR only when the domain-modeling criteria say the decision warrants one.

Do not implement the resulting plan or design until the question frontier is empty and the user explicitly confirms the shared understanding.
