Revision: 71e1cacf1437a11220307120e63e30bc275312d4

Unmodified upstream Galmuri11.ttf; not an original Grid-Caster typeface.
The font supports modern Hangul. Its native design size is 12 px.
Unity uses dynamic HintedSmooth rendering to preserve small strokes at the
existing responsive Canvas sizes. Regular style avoids synthetic bold.
The previous NeoDunggeunmo asset remains intact.
